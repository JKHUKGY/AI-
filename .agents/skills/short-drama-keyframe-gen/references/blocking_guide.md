# 走位设计指南（人物在场景里站哪、朝哪、在干什么）

这一步做不好，后面全白做：图生视频阶段首帧是用 `--image <path> 0 1.0`
**焊死**的（见 `short-drama-video-gen/references/shot_card_schema.md`
`first_frame_strength` 一节）。首帧里人站错了位置、朝错了方向，视频阶段
改提示词**没有任何用**——模型只会在"照首帧"和"照文字"之间摆烂，表现为
人物姿态不动只有镜头在动。所以关键帧的走位是**不可返修的一次性决定**。

## 先看这一步真实是怎么失败的

三张实拍证据，都在 `output/出狱后我成为了非洲矿王/keyframes/ep03/`：

**1. 全员正脸 + 列队站位**（`ep03_镜10/ep03_镜10_00.png`）

分镜表要的是"举荐的人—动心的人—要否定的人"三角关系，视觉焦点在苏慧。
实际出图：刘兰、苏慧、顾万通三个人**站在同一条纵深线上横排开**，刘兰和
苏慧都平着脸朝镜头、彼此之间没有任何视线关系，只有顾万通是侧面。看起来
像三个人在客厅里合影，不像一场戏。

当时那条 prompt 已经写了 `苏慧在画面中景偏左`、`顾万通在画面右侧近端`、
`刘兰在画面左侧`——**位置写了，朝向没写**（只写了视线和表情），纵深只对
顾万通写了"近端"。模型于是把没约束的两个人默认成正脸、默认成同一深度。

**2. 景别从"中景"漂成全景**（同一张图，以及 `ep03_镜03/ep03_镜03_00.png`）

两条 prompt 结尾都有 `【景别】中景（双人/三人）`，出来的都是**全身带脚、
画面下方 40% 是空地板**的全景。原因不是模型不懂"中景"，是同一条 prompt 里
还写着"保持场景的陈设、材质、光影和相机视角与参考图1完全一致（不要重新
设计房间、不要换角度）"——底板本身就是一张空房间大全景，这句把取景范围
也一起锁住了。**两条指令打架时，被参考图撑着的那条赢。**

**3. 否定句拦不住走位问题**

`ep03_镜03` 的避免尾块里明确写了 `顾万通正面朝镜头`、`刘兰站姿直立不前倾`；
`ep03_镜10` 写了 `苏慧低头含胸（这一镜她要抬头）`、`位置左右互换`。
出图里刘兰依然站得笔直、苏慧依然是平脸。否定句在这里的实际作用是把
"正面朝镜头"这个概念又注入了一遍。

结论：走位必须是**正向的、逐人的、带枚举的结构化字段**，而且景别必须和
底板锁定句和解。这就是 `keyframe_card_schema.md` 那张卡的由来。

## 规则一：每个人都要有相对镜头的朝向，而且一镜最多一个正脸

`camera_relation` 五档，从最露到最不露：

| 值 | 中文 | 什么时候用 |
|---|---|---|
| `front` | 正面对镜头 | **一镜最多 1 人**；单人正打近景/特写、或剧本明确要"直视观众"时该用就用 |
| `three_quarter_front` | 3/4 侧面朝镜头 | **对话戏的主力**。能看清表情，又有朝向感 |
| `profile` | 完整侧面 | 两人对峙、并肩、一人打断另一人 |
| `three_quarter_back` | 3/4 背面（过肩） | 正反打里**靠近镜头那一个人**的标准写法 |
| `back` | 完全背对镜头 | 进门/离场/看向纵深处的东西/刻意藏表情 |

硬规则（脚本会拦）：

1. 一镜里 `front` 最多 1 人。
2. **两人以上的镜头，至少要有 1 人是 `profile` / `three_quarter_back` /
   `back`。** 全员 `front`+`three_quarter_front` 就是"合影"，直接判不合格。

**不设"全集正脸不超过 X%"这类配额。** 正脸该不该用，按这一镜的实际需求判断
——打脸镜、直视观众的钩子镜就该给正脸，硬凑比例反而会为了指标改设计。
脚本只拦上面两条**单镜内**的结构性规则，审阅表会把这一集的朝向分布列出来
（正面多少人次 / 侧面过肩背对多少人次）供人一眼扫过，但不替人下结论。

“谁该背对镜头”的默认答案：**离镜头最近的那个人**。近端人物过肩，远端
人物露 3/4 正脸，观众的视线自然跟着近端人的肩膀送到远端人的脸上——这也是
`ep03_镜03` 唯一做对的地方（顾万通近端 3/4 背面，刘兰远端 3/4 正面）。

## 规则二：多人镜必须有纵深层次

`depth` 三档 `near` / `mid` / `far`，两人以上**至少出现两个不同的层**
（脚本硬拦），并且 `pos_x` 不许全部相同。

原因就是 `ep03_镜10` 那张图：三个人同层横排，画面立刻变平、变成合影。
分好层之后近端的人自然更大、更靠画面下缘，远端的人更小，画面才有空间。

竖屏 9:16 的额外约束：横向只有三个有效格位（`left`/`center`/`right`），
所以**三人以上必须靠纵深分开**，不能靠横排。四人以上考虑把一部分人处理成
虚焦身影（写进 `posture_zh`，不单独给参考图），这也是分镜表备注里常写的
"画面左侧虚焦处能看到沙发上刘兰与顾浩的身影轮廓"那种处理。

## 规则三：视线要有落点，且和朝向、和对手的位置对得上

`gaze_at` 必填，允许的落点：另一个人物名 / `lens` / `off_left` /
`off_right` / `off_up` / `off_down` / `prop:<道具名>`。

- 看着画面右边的人，身体就得朝画面右（`body_dir: screen_right`），
  脚本按 `pos_x` 的先后顺序核对。
- **对视 ≠ 两人都看对方就行**。真的对视要求两人 `body_dir` 相反
  （一个 `screen_left`、一个 `screen_right`），否则两人是在朝同一边看。
- 刻意的"不对视"要写成两个不同的落点，而不是写"避免对视"：
  `ep03_镜03` 的正确写法是刘兰 `gaze_at: 顾万通`、顾万通
  `gaze_at: off_down`——这就是"她凑近问、他懒得答"。

## 规则四：正反打的左右必须翻转（越轴）

同一场戏、同一组人，`A主机位` 和 `B反打` 两镜里每个人的 `pos_x` 必须
**正好相反**。依据是 `scenes.md`「空间关系」块末尾那行速记，例如 SC03：

> 南=玄关/楼梯（A 相机位置）、北=落地窗纵深端、西=电视墙+转角沙发、
> 东=玻璃幕墙+单人皮沙发。A 看北 → 左=西/右=东；B 看南 → 左=东/右=西。

脚本会对同场景、共享同一批人物、底板一个是 `A主机位` 一个是 `B反打` 的
两张卡做这条检查，同侧就报 ERROR。分镜表「画面描述」里的（画面左侧/右侧）
标注和「机位」列对不上时**先回去问**，不要自己挑一个。

## 规则五：景别要写成裁切，而不是写成形容词

见 `keyframe_card_schema.md` 的 `framing` 一节：`shot_size` + `subject_frac`
（数）+ `crop_zh`（切在人身上哪里）+ `plate_crop_zh`（取底板的哪一块、
哪些东西因此看不到）。四个一起才拦得住漂移。

装配器把景别和裁切放在**参考图声明之后、走位之前**，不再放在提示词末尾
——`ep03` 那批把 `【景别】` 放在一大段散文尾部，是失败的一部分。

## 规则六：动作写"这一瞬间"，不写过程

关键帧是一张静态图。分镜表「运动描述」列写的是"第 0.8 秒起…第 2.0 秒…"
那种过程，**那是下一步（图生视频）的输入，不是这张图的内容**。

- ✗ `刘兰双手一撑猛地站起、朝画面右前方快步迎上两步` —— 三个时刻，模型
  只能挑一个，挑哪个不受控。
- ✓ `刚从沙发上站起、上身明显前倾、双脚一前一后处在快步迎上来的中间态`
  —— 一个可画的瞬间，而且这个瞬间**同时暗示了前后动作**，正好适合当
  图生视频的首帧。

选哪个瞬间有个准则：**选这一镜运动的起点**，因为它要当视频的首帧。
如果分镜表的「运动描述」写了"起始：…"，那句就是这张图要画的东西。

## 规则七：机位不是运镜，这一步只有机位

`推/拉/摇/移` 这些在这一步一律不写（`ep0X.md` 的「运镜」列留给下一步）。
这一步只有"相机站在房间哪个位置往哪看"，而且它**主要是靠选对底板体现的**，
`camera_zh` 那句英/中文只是给模型一个对齐用的说明。

历史上出现过把机位当运镜写进 prompt 的情况（`全景镜头(缓慢横摇)`、
`近景镜头(骤然推进)`），括号里的字对一张静态图没有意义。

## 一张卡填完之后自查（人工，出图之前）

1. 这一镜里有没有人的 `camera_relation` 是我**没想过**就填成 `three_quarter_front`
   的？——默认值就是失败的来源。
2. 把 `people[]` 按 `depth` 排一遍：近端那个人是不是过肩/背对？
3. 视线连起来能不能画成一条线？有没有人在看空气（`off_*` 用得对不对）？
4. `subject_frac` 和 `crop_zh` 描述的是同一件事吗？
5. `plate_crop_zh` 里说的"看不到的东西"，在 `plate_read_zh` 里真的存在吗？
6. 这一镜的走位，能不能承接上一镜、能不能接下一镜（人不能瞬移）？
