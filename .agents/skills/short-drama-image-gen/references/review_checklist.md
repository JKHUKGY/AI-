# 出图验收清单

每一轮生成完，Claude 必须用 Read 工具实际打开每一张新生成的图片查看（图片
是多模态输入，直接读文件路径即可"看到"），逐张对照下面清单判断是否可用，
不能只看文件是否生成成功就当作通过。

## 单张图片自查

- **是否符合角色档案**：发型发色、瞳色、肤色、体态、服装是否和
  `characters.md` 里这个造型的描述一致。
- **五官/肢体是否正常**：有没有面部崩坏、多余或缺失的手指肢体、镜像不对称
  等生成模型常见问题。
- **构图是否可用**：是否竖屏 9:16、主体是否在安全区内（没有被裁切掉头部
  或关键动作）、背景是否干净（角色立绘不要杂乱背景，场景图里角色档案要求
  "无人物"的空镜头不该混进人物）。
- **是否有水印/文字/多余 logo**：模型有时会在图里生成不需要的文字水印，
  出现就判不可用。
- **画风是否统一**：色调、打光风格是否和已经选定的其他角色/场景图一致，
  尤其是同一批次里前后生成的图不能一张写实一张卡通混搭。
- **情绪/动作是否达标**：如果这张图对应的是分镜表里某个具体镜头（比如
  "震惊表情"），要看这个表情/动作是否读得出来、够不够到位，不够到位也判
  不可用，不要为了省事将就。

## 三视图专属检查

角色的三视图 job 除了上面的单张自查，还要额外确认：

- **三个视角是不是同一个人**：正面、侧面、背面的脸型、发型发色、体态、
  服装是否一致，不能出现"正面是这张脸，侧面明显换了个人"的情况。
- **三个视角比例是否一致**：身高、身材比例、服装细节在三个视角里应该
  对得上，不能出现侧面明显更瘦/更矮之类的比例错位。
- **是不是真的给了三个视角**：模型有时会偷懒只生成正面+侧面、或者把
  "背面"画成又一个正面，这种也判不可用，需要在 prompt 里更明确地要求
  "背面视角看不到正脸、只有后脑勺和背部"之类的描述后重新生成。
- **半成品不能拆着用**：如果一版三视图里只有某一个视角画得好、其余两个
  崩了，整版判不可用、重新生成，不要把好的那个视角单独抠出来当基准图，
  否则后续需要另外两个视角时又要重新生成，反而破坏一致性。

## 同一角色跨造型的一致性抽查

如果这个角色有多套造型（比如"落魄期"和"归位日常"各出了一版三视图），
选出来之后并排看一遍：除造型/服装差异外，脸型、五官比例、发型发色是否
统一，是不是能一眼认出这是同一个人。如果明显不像同一个人，说明两版三
视图之间没有有效关联（角色三视图彼此独立生成、互不引用是正常的，但
"长得不像同一个人"仍然不可接受），需要在 prompt 里把这个角色不随造型
变化的核心长相特征（脸型、瞳色、五官）描述得更具体后重新生成。

## 何时判定"这批不可用，需要重新生成"

- 一个任务 (`job`) 首轮生成的几张里一张能用的都没有。
- 能用的图明显偏离角色档案关键特征（比如瞳色、发型都不对）。
- 明显的生成瑕疵（肢体错乱、面部崩坏）超过一半。

出现以上情况時，调整 `prompt`（更明确具体的描述、把之前不可用图里暴露的
问题写成"避免：xxx"加进反面提示词里）后重新生成一轮，而不是将就选一张
勉强能用的图凑数。

## 何时停止重试、上报用户

单个任务连续 3 轮（累计通常已有 9-12 张变体）仍然选不出可用图，就停下来，
把这 3 轮里最接近能用的几张图和具体问题点告诉用户，请用户决定是调整角色
设定、换措辞、还是接受用当前最好的一张将就用——不要无限重试消耗调用次数
和用户的 API 额度。
