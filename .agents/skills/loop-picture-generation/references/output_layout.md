# 给人看与机器文件分开

产物按用途分成两个入口；向用户汇报优先给阅读入口，而不是要求用户在JSON和生成日志中找结果。

```text
output/<剧名>/
  README.md                    首屏链接到阅读首页
  给人看/
    阅读首页.html / README.md    分镜、图片与当前进度的清晰导航
    01_分镜表/                  按集排列的可读分镜表
    02_已选图片/                人物、场景、各集主帧与逐镜关键帧；只展示已选素材
    03_待处理图片/              未通过/备选候选与具体问题，和已选分开
    04_设定/                    画风、人物档案、场景设定
    05_审阅与验收/              需要人确认的提示词审阅表、台词核对、验收报告
    进度.md
  机器文件/
    制作过程/                  源卡、原文、派生任务、审批、代理记录、日志、候选原档
    刷新阅读入口.py             若项目已有此脚本，更新源数据后执行
```

按**用途**分类：提示词审阅表即使来自JSON也属于给人看的材料；内部日志即使是Markdown
也进入机器文件。图片可以用相对链接引用同一原图，避免复制大文件；阅读副本的相对链接
须按新目录修正，正文、台词和镜号不得因整理而改写。

整理已有项目时保留源数据和历史记录。移动制作目录后为原 storyboard/assets/keyframes/videos
路径保留兼容链接，校验所有原路径仍可读取，并修复继承素材的相对软链接。
只在已授权项目范围内移动或写入，不移动别的版本的共享原图。

阅读副本从制作源数据刷新；生成或验收完成后同步更新目录、图片分组与进度，移除已过时的
自动生成图片入口但保留原图。不得仅凭候选存在就列为已选；主帧和逐镜关键帧分别计数。
主代理负责合并和刷新阅读入口，子代理仅写分配给自己的机器工作目录。
