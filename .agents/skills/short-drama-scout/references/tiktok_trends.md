# TikTok 短剧热门题材参考

本文档总结的是行业里公开可见的"题材套路"层面的创作参考（这类套路本身不受版权保
护），不针对任何具体版权作品；具体人物设定、台词、情节要原创设计，不要照抄任何
已知作品的人物姓名或桥段。

清单会随行业风向变化，使用前建议按 `SKILL.md` 里说的方法用 WebSearch 交叉验证
一下当前最新热度，搜不到网络就以本清单为准。

## 一、中文向题材（国内微短剧 / 面向中文观众的 TikTok 内容）

1. **身世逆袭 / 千金归位**：落魄千金回归亲生豪门家庭、错换人生、真假千金互换。
   爽点：被低估 → 身份反转 → 扬眉吐气。
2. **重生复仇**：主角带着上一世记忆重来一次，提前布局手刃仇人/避开渣男渣女。
   爽点：先知视角的降维打击。
3. **战神 / 兵王归来**：被家人瞧不起的赘婿或上门女婿其实深藏不露（军人/富豪/
   高手）。爽点：扮猪吃虎、当众打脸。
4. **霸道总裁甜宠**：契约结婚/闪婚/先婚后爱，总裁人设强势但独宠女主。爽点：
   被强者偏爱的安全感 + 甜蜜互动。
5. **恶毒女配 / 替身文逆袭**：原本注定悲剧的工具人角色觉醒，逆转剧本。爽点：
   打破"配角宿命"的反套路快感。
6. **离婚 / 独立觉醒**：被家庭或婚姻辜负的女性重新证明自己，事业线、复仇线并
   行。爽点：现实共鸣 + 扬眉吐气。
7. **马甲文 / 扮猪吃虎**：主角隐藏真实身份（首富/大佬/高手），被伤害后当众
   掀底牌。爽点：信息差带来的强烈反差感。

## 二、出海题材（英语配音发布到 TikTok/Instagram 的竖屏短剧常见类型）

1. **Secret Billionaire / CEO Romance**：伪装成普通人的隐藏亿万富翁，契约婚姻、
   办公室恋情。
2. **Revenge Story**：被抛弃/陷害的主角逆袭复仇，常和"重生""身世逆袭"结合。
3. **Werewolf / Fated Mate**：超自然设定 + 命定伴侣，欧美观众接受度高。
4. **Fake Marriage / Secret Baby**：假结婚、隐婚生子、多年后身份曝光。
5. **Mafia Boss Romance**：黑帮老大人设 + 甜宠/复仇双线。

## 三、跨题材通用的强钩子结构

不管选哪个题材，以下节奏规律都适用：

- **开场即冲突**：不用"引子/日常"开场，第一句台词或第一个镜头就要有矛盾。
- **信息差反转**：让观众比角色先知道真相（或反过来），制造"想看角色发现真相"
  的期待感。
- **每集一个爆点**：至少一个强烈反转或情绪高点，不要平铺直叙走流水账。
- **硬切结尾**：在冲突最高点切断，不给"缓冲收尾"，逼观众点开下一集。
- **快速立人设**：主角的核心标签（比如"扮猪吃虎的马甲大佬"）要在前 3 集内立
  住，后面持续强化，方便观众追更时秒懂剧情逻辑。

## 四、TikTok 平台运营侧的偏好（写大纲时顺带考虑）

- 系列剧集要方便"续播"：每集结尾的钩子要能撑到用户主动点进主页找下一集。
- 封面/开头字幕常用悬念式短句（例如"她万万没想到，亲生父亲竟然是……"）代替
  剧透式简介。
- 评论区常见运营话术，例如引导"想看反转扣1""下一集见证她翻身"；但内容本身
  才是留存核心，运营话术只是锦上添花，不要本末倒置。
