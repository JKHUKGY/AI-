- 提示词、图片、项目文字筹备均有服务端取消接口；任务所属项目仍受登录与项目授权检查约束。
- Codex 与图片生成启动独立进程组。终止结束组内进程；提示词提交与取消互斥，迟到结果不写入历史。
- 项目筹备终止保留已写文件与检查点，支持继续；手动增删结构后禁止恢复旧规划。
- 前端面板、顶部任务栏、项目筹备页均有终止入口。跨页与刷新保留原草稿，不重启任务。
