# claude-code-docs — 机制日志

这个 Skill 用什么方式读 Claude Code 的官方文档, 以及为什么这么设计。最新的条目在最上面, 顶部那条
描述的就是当前的机制。条目只追加, 不改写。

## 2026-07-30 — check

**结论。** 这是第一条记录, 用来建立基准。这个 Skill 此前是手写的, 没有机制记录, 所以这次 check 无从
对比。机制本身没有变化, 也很健康 —— T0/C0 都仍然成立 —— 但写进 SKILL.md 的那些数字已经过期, 并且
缺了两条召回规则。

**这个站点是怎么读的。** 索引是 `https://code.claude.com/docs/llms.txt`: 38,847 字节(约 9,700
tokens), 174 条, 只有一个扁平的 `## Docs` 分节, 100% 的条目都带真实描述而不是模板话。每个链接都以
`.md` 结尾, 都在 `code.claude.com` 域名下。`/llms.txt` 和 `/docs/.well-known/llms.txt` 提供的是
逐字节相同的副本。Skill 每次提问 WebFetch 一次完整索引, 按描述(而不是标题)分诊, 然后每批抓 1–3 页,
上限 9 页。页面 URL **原样取自索引** —— 它们本身就以 `.md` 结尾, 直接返回原始 Markdown;
`md-suffix`、`index-md`、`txt-suffix` 这些变体全部 404, 所以没有「twin」需要拼。页面体积差 25 倍:
从 10,628 字节(`troubleshooting.md`)到 272,484 字节(`settings.md`), 其中 `hooks.md` 是 242,078
字节, 而同一页的 HTML 是 2,423,751 字节。同目录的 `llms-full.txt` 有 6,556,407 字节(约 164 万
tokens), 那是全文 dump, 任何情况下都不要抓。

**为什么是这个设计。** 索引分层 **T0**, 内容分层 **C0**。选 T0 是因为 38,847 字节 ≤ 40,000 字节的
阈值, 且描述覆盖率 100% ≥ 60% —— 整份索引一次 WebFetch 就装得下, 所以不需要查询脚本、不需要
`docs-source.json`、也不需要缓存层。C0 且**不设 `url_template`**: 这正是那种反射性地套
`{url_no_slash}.md` 规则就会把 Skill 弄坏的地方。放弃 **T1**: 索引只有一个分节, 做路由就等于自己
发明一套分类法。放弃 **T2**: 它能把每次提问的开销从约 9,700 tokens 降到约 200, 但 T0 的召回率是白
送的 —— 174 条描述全在上下文里, 这正是同义词错配那个测试根本不需要升级就能命中的原因。放弃 **T4**:
探测路径下没有 sitemap, 所以覆盖率算不出比例, 但 174 个落在文档域名下的具体 `.md` 叶子页说明这是一
份叶子级索引, 不是入口页清单。

**什么情况下这个判断会被推翻。** 索引超过 40,000 字节 → 改用 T2(复制 `docs_query.py`, 加一份省略
`url_template` 的 `docs-source.json`, 把流程第 1 步改写成 `search`, 第 3 步的升级阶梯原样保留,
因为那时它从保险变成了主力)。这是眼下真实的风险: 38,847 字节已经是阈值的 **97%**, 而
`whats-new/2026-wNN` 周报页大约每周新增一条, 还要加上新功能页。索引出现真正的 `##` 分节 → 改用 T1,
优于 T2, 因为那套层级是官方维护的。`.md` 链接消失或开始 404 → 重新探测内容契约。描述退化成模板话 →
进入 T5 讨论。Anthropic 推出官方文档 MCP server 或搜索 API → 这个 Skill 可能变成冗余或互补; 截至本
条目为止还没有。

**重建时必须保留的东西。** `description` 里的中文触发词 —— 索引是纯英文的, 没有任何脚本能推导出它们。
「When to use this skill」下面的领域清单, 是从 slug 聚类手工归纳的, 因为索引只给了一个分节名。指向
`claude-api` Skill 的范围边界说明, 这是本地约定, 文档站点上看不到。

**当天跑的验收测试。** `hook` → 索引命中 17 条, 覆盖 `hooks.md`、`hooks-guide.md`、
`agent-sdk/hooks.md`。同义词错配 `resume` → 标题命中 0 条、描述命中 5 条, 落在 `sessions.md`
(*Manage sessions*)上, 全程不需要升级。非英文 `钩子` → 命中 0 条, 而 `hook` 命中 17 条; 这个测试
证明必要的「先翻成英文」规则现已写进流程第 3 步。内容抓取 `hooks.md` → 242,078 字节 Markdown。
