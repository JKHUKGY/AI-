# 历史决策与研究

路径相对仓库根；长文先查标题/关键词，只读命中段落。

| 问题 | 文件及定位词 |
|---|---|
| 原始需求、上次做了什么、日期决策 | `需求.md`，按日期追加；最近记录可先 `tail -n 60 需求.md` |
| 分镜、走位、机位组、生成单元 | `研究.md`，第 1 段 / `1.1` 至 `1.6` |
| 图像提示词、参考图、裁切、一致性 | `研究.md`，第 2 段 / `2.1` 至 `2.8` |
| 视频提示词、运镜、台词与音频 | `研究.md`，第 3 段 / `3.1` 至 `3.5` |
| 首帧锁死、CFG、token 预算 | `研究.md`，第 4 段 |
| 卡→装配→校验、人工闸门、验收、重试 | `研究.md`，第 5 段 |
| 提示词模板 / 待改事项 / 连戏 | `研究.md`，第 6 / 7 段及末尾追加 |
| 某模型实测能否做到 | 当前宿主 `short-drama-video-gen/references/model_capability_ledger.md` |
| 某剧计划及交接 | `output/<剧名>/PROGRESS.md`（若存在）；完成情况查实际文件 |

例如 `rg -n '^#{1,3} ' 研究.md` 查标题行号，再 `sed -n '起行,止行p' 研究.md`。
无 `rg` 时用 `grep -nE '^#{1,3} ' 研究.md`；找具体决策可先 `grep -nF '关键词' 需求.md`。
只读匹配章节至下一同级标题；不要因一个问题加载整篇研究或所有历史。
