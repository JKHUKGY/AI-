# 项目目录

路径均相对仓库根。只用于区分项目，不代表完成进度；版本选择以本次用户指令为准。

| `output/` 下的目录 | 用途 |
|---|---|
| `出狱后我成为了非洲矿王/` | 原版制作产出 |
| `出狱后我成为了非洲矿王_v2/` | 按新版机位组、三视图、走位规则重做；可作素材复用与对照 |
| `出狱后我成为了非洲矿王_v3/` | 后续制作版本；计划及交接看该目录的 `PROGRESS.md`，完成情况查磁盘 |
| `千金归位/` | 早期全流程样例，无独立 `storyboard/`；故事样例还在 `short-drama-scout/examples/` |
| `暗局/` | 独立短剧项目 |
| `雪山决斗/` | 单镜试拍，使用 `refs/` 和 `videos/shot01/` |
| `_pilot_机位组/` | 验证场景 A/B/C/D 机位底板的试拍 |
| `单图可控视频_Demo/` | 单图经深度/2.5D控制LTX的研究与15秒试拍；先读 `可行性报告.md` 或 `给人看/演示首页.html` |

确定目录后，只读 [产出文件](outputs.md) 的路径模板或直接访问目标。
未列出的项目先 `find output -mindepth 1 -maxdepth 1 -type d`，不要递归列素材。
进度运行当前宿主 index 的 `scripts/snapshot.py --project <完整剧名>`。
脚本按前缀筛选，原版名可能同时匹配 v2/v3；只引用用户指定目录的报告。
