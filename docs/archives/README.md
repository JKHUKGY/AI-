每组包含 `.tar.gz` 包和 `.manifest.json` 清单。归档包保留仓库相对路径，并同时保存媒体、报告、测试脚本、JSON 和 HTML。本批主动移除的范围是清单中标记的媒体及发布包；并行清理还移除了部分原始目录，实际缺失的文本记录在 `local_text_files_missing_at_final_check`。本地保留本目录的归档清单和恢复说明；查看完整历史报告及其媒体链接时，先取回对应归档。模型缓存、运行环境和当前制作文件未纳入本批。

每个包上传后核对远端大小、MD5 和 SHA-256；首组另外下载核对了 SHA-256。清单同时保存在云端和本地，逐组校验方式见 `verification` 字段。删除本地副本前再次核对单文件 SHA-256，期间有变化的文件保留。

## 取回

1. 在 JSON 清单中找到所需组的 `remote`、`archive` 和 `archive_sha256`。
2. 用 `rclone copyto '<remote>/<archive>' 'tmp/<archive>'` 下载到仓库临时目录。
3. 运行 `sha256sum 'tmp/<archive>'`，与清单中的 `archive_sha256` 对比。
4. 核验一致后，在仓库根目录执行 `tar -xzf 'tmp/<archive>' --keep-old-files`，只补回缺失文件。已保留的文本会提示“文件已存在”，不会被覆盖；也可以先解包到独立目录再按清单取回。
5. 对照清单的 `files[].sha256` 核验恢复的文件，再删除下载包。

这些选择性历史归档不使用项目整卷的 `.archived.json`，不要用 `scripts/archive.py restore` 恢复本批。已有项目整卷归档仍按 [原归档说明](../../scripts/ARCHIVE.md) 操作。
