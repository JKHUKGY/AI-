# 人物形象设计提示词模板

给每个主要角色写一份，供用户拿去 Gemini（或其他图像模型）生成角色立绘。字段
可按角色实际情况增减。全部角色提示词开头必须带同一句"画风锚点"，保证全剧
画风统一。

## 画风锚点（全剧统一，写在每个角色/场景提示词最前面）

不要在这里临时现编——原句来自 `SKILL.md` 第 1 步"先定视觉风格与叙事基调"
的结论（选型对比见 `references/style_guide.md`）。示例：写实风格故事可能是
`现代都市短剧写实照片级质感，电影感打光，竖屏 9:16 构图，色调偏冷/暖（按剧
集基调定），无水印无文字`；动漫风故事则应换成对应的画风描述（如"日系赛璐璐
上色二次元风格，扁平光影，竖屏 9:16 构图"）。一旦第 1 步定下来，全剧所有角色
和场景提示词都要原样复用这一句，不能中途换风格、也不能各角色各写各的措辞。

## 提示词正文（示例结构，实际按角色替换）

```
[画风锚点] + 一名[年龄][性别]，[发型发色]，[瞳色]，[肤色]，[体态描述]，
穿着[服装描述]，[气质关键词对应的姿态/表情]，正面全身像，干净背景，
角色设计参考图/角色立绘，[分辨率/画质要求]
```

## 需要一次性生成的差分（供后续所有分镜复用，避免每个镜头重新设计长相）

- 正面立绘（默认表情/姿态）
- 侧面/背面（用于转身图，保证转头类镜头一致性）
- 表情差分：中性、微笑、震惊/愤怒（二选一或都要）、哭泣/委屈
  - 每个表情差分提示词 = 上面的提示词正文，把"正面全身像"换成"近景肖像，
    表情为[表情描述]"，其余部分（画风锚点、发型服装等）保持完全一致，这样
    才能保证同一角色在不同表情镜头里还是同一张脸。

## 反面提示词（negative prompt，如目标模型支持）

- 避免：多余肢体、手指数量错误、五官崩坏、水印文字、镜像不对称、风格与其他
  角色不统一
