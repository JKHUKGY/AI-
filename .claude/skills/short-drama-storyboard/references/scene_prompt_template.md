# 场景/背景设计提示词模板

给每个会用到的场景写一份，供用户拿去 Gemini（或其他图像模型）跑图。同一场景
不同时间段（白天/夜晚/雨天）只在剧情确实需要时才分别生成，避免为每一集重复
生成同一个地点浪费成本。

## 场景档案

- 场景编号/名称（对应场景清单，比如"女主家客厅""公司天台"）：
- 出现集数：
- 室内/室外：
- 时间/天气（白天/夜晚/黄昏/雨天等，只在剧情需要变化时才拆分成多份）：
- 氛围/情绪关键词（比如"压抑""温馨""紧张对峙"）：
- 关键陈设/构图元素（会在多个镜头里反复出现、需要保持一致的背景细节，比如
  "落地窗""墙上的全家福""办公桌摆件"）：
- 光影/色调设定（呼应本场景情绪基调，与角色提示词的画风锚点色调呼应）：
- 会用到这个场景的镜头/集数（方便一次性生成多角度背景图供不同分镜复用）：

## 提示词正文（示例结构，实际按场景替换）

```
[画风锚点，与角色提示词共用同一句] + [室内/室外]场景，[关键陈设描述]，
[光影/色调描述]，[氛围关键词]，无人物，空镜头/场景原画，[分辨率/画质要求]
```

如果需要"人物+场景"合成的分镜关键帧图（而不是纯背景图），在此基础上加一句
引用对应角色提示词里的关键特征描述 + 本镜的动作/构图要求，而不是重新描述整
个场景——复用已经定好的场景描述文本，只替换动作/人物部分，保证背景不跳戏。

## 复用建议

- 同一房间不同镜头（比如同一场对话戏里的正反打两个机位）尽量只生成 1-2 张
  背景图，用裁切/构图调整覆盖不同镜头，而不是每个镜头都重新生成背景。
- 建立"场景原画库"，每张图标注对应的提示词版本和适用镜号范围，方便后续分集
  复用、也方便发现"这个场景其实还没生成过"的遗漏。
