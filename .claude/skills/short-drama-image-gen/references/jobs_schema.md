# jobs.json 格式说明

`scripts/generate_images.py` 的输入是一个 JSON 数组，每个元素是一个"生成
任务"。由 Claude 在动手生成之前，读 `characters.md` / `scenes.md`（或用户
直接给的提示词），把里面的占位符（如 `[对应造型服装描述]`、`[画风锚点]`）
替换成具体文字后组装成这个文件——脚本本身不做任何 markdown 解析。

## 字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | 任务标识，会作为输出子目录名和文件名前缀。建议用 `角色名_造型_差分类型` 或 `场景编号_名称` 这种能一眼看出对应哪张资产的命名，比如 `苏晚_落魄期_正面`、`SC03_客厅_夜晚版`。 |
| `prompt` | 是 | 完整的最终提示词文本，画风锚点、角色描述等占位符必须已经替换成具体内容，不要留 `[xxx]` 方括号占位符进这个文件。 |
| `count` | 否，默认 3 | 这一任务这一轮要生成几张变体。首轮建议 3-4 张，够挑一张能用的；如果这是"追加生成"的返工轮次，可以设小一点（1-2）。 |
| `ref_images` | 否 | 参考图片的本地文件路径数组。用于"编辑/保持一致性"场景，比如已经选定了某角色的正面立绘，要生成同一角色的表情差分或换装图，把选中的立绘路径填进来，模型会尽量保持同一张脸。留空数组表示纯文生图。 |

## 示例

```json
[
  {
    "id": "苏晚_落魄期_正面",
    "prompt": "现代都市短剧写实照片级质感，电影感打光，竖屏9:16构图，主色调金属冷灰与暖金色交替，无水印无文字 + 一名24岁东亚女性，黑长直发前期略毛躁自然垂落，深棕色瞳孔，肤色偏白略显疲惫，身材纤瘦挺拔，穿着洗旧的浅色针织衫+牛仔裤，眼神隐忍低头含胸，正面全身像，干净背景，角色设计参考图/角色立绘，高清细节。避免：多余肢体、手指数量错误、五官崩坏、水印文字",
    "count": 4,
    "ref_images": []
  },
  {
    "id": "苏晚_归位日常_表情_震惊",
    "prompt": "现代都市短剧写实照片级质感，电影感打光，竖屏9:16构图 + 同一位角色，近景肖像，表情为震惊，嘴微张、眼睛瞪大，其余发型服装保持与参考图完全一致。避免：多余肢体、五官崩坏、水印文字、与参考图不是同一张脸",
    "count": 3,
    "ref_images": ["output/千金归位/assets/苏晚_归位日常_正面/苏晚_归位日常_正面_00.png"]
  },
  {
    "id": "SC03_客厅_日间",
    "prompt": "现代都市短剧写实照片级质感，电影感打光，竖屏9:16构图 + 室内客厅场景，白色真皮沙发，落地窗自然光，壁炉，吧台摆放红酒杯，精致but略显冷淡的陈设，无人物，空镜头/场景原画，高清细节",
    "count": 3,
    "ref_images": []
  }
]
```

## 关于 negative prompt

Codex CLI 的 image_gen 工具没有独立的 `negative_prompt` 字段，"避免出现什么"要直接写
进 `prompt` 文本末尾（参照上面示例里的"避免：xxx"一句），不要在 jobs.json
里额外造一个字段指望脚本处理，脚本不会读取。
