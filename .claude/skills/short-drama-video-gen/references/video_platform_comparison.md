# 图生视频平台现状对比（2026-08 调研，用前先自行核实版本号）

行业更新很快，下面的信息是 2026 年 8 月联网调研的结果，**用之前先跟用户确认
一下版本号/价格有没有变**，不要当成永久不变的事实照抄给用户。选平台时优先
考虑：这个镜头要不要首尾帧控制、要不要多参考图保一致性、用户有没有对应
账号/预算。

## 现实前提：没有免 API key 的路径了

`short-drama-image-gen` 能白嫖是因为 Codex CLI 的 `image_gen` 内置工具。
视频生成没有对应物：

- **OpenAI Sora**：网页版/App 已于 2026-04-26 下线，API（$0.10/秒起，Pro
  档 $0.30-0.70/秒）计划 2026-09-24 停运。**不要再推荐用户走 Sora**，就算
  当前还没停运，窗口期也快关了。
- Codex CLI 本身不带任何视频生成工具，`codex exec` 没有等价的 `video_gen`。

所以下面每个平台都需要用户自己有订阅/账号，本 skill 只负责把提示词和参考图
配好，不负责免费调用。

## 自建模型：LTX-2.5（Lightricks LTX-2 仓库，用户自己租显卡部署）

和上面几家 SaaS 不同，这是用户自己控制的推理环境（比如在 vast.ai 租显卡
装好开源仓库），不是订阅制平台，本 skill 对这种情况提供了实际的 SSH 调用
脚本，见 `ltx2_self_hosted.md` 和 `scripts/ltx_ssh_submit.py`，不需要用户
手动上网页操作。接口细节（首尾帧参数名、负面提示词是否通用、竖屏支持）
截至 2026-08 调研仍有部分未经官方文档完全确认，第一次用之前务必先
`--dry-run` + 小范围测试，不要直接批量提交整集。

## 选型建议（按短剧场景）

- **需要严格保持同一张脸+同一件道具跨多镜头**：优先 Vidu Q2（参考图数量
  最多）或 Veo 3.1 Ingredients。
- **国内团队、预算有限、要走网页版手动生成**：可灵或即梦，两者都原生支持
  首尾帧，且中文提示词直接可用，不用先翻译成英文。
- **风格化/二次元短剧**：PixVerse 系。
- **想要视频自带同步音频省一道配音合成的步骤**：海螺 H3 或 Veo 3.1，但
  仍建议先按 `video_review_checklist.md` 核对音画同步质量再决定是否用它替代
  独立配音环节，不要盲目信任"自带音频"就一定对得上台词。
- **Sora**：不推荐，处于下线/停运窗口期。
