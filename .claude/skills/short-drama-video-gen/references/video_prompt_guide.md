# 图生视频提示词组装指南

关键帧图已经锁定了人物长相、服装、场景——图生视频的提示词**不需要再重复
描述这些**，核心任务只有一件事：说清楚"接下来发生什么、镜头怎么动"。这一点
是 Runway 官方图生视频指南反复强调的："Effective image to video prompts
focus almost exclusively on motion"，堆砌外观形容词只会稀释动作指令的
权重，甚至让模型误以为要重新设计人物。

## 提示词公式

```
[动作分解：起始姿态(可省，关键帧已定) → 过程关键点1 → 过程关键点2(可选) → 结束姿态/定格]
+ [运镜：推/拉/摇/移/跟/固定，翻译自分镜表"运镜"列]
+ [节奏与速度：缓慢/克制 或 骤然/短促，配合分级]
+ [光影/氛围变化（如果本镜需要，比如"手机屏幕光在脸上忽明忽暗"）]
+ [负面提示词]
```

## 第一步：把"运动描述"列展开成分阶段动作

`ep0X.md` 的"运动描述(S/A级需要)"列通常是一句简写（比如"她哭了"
"震惊后瘫坐在地"），照抄进 prompt 会让模型自己脑补一个不可控的完整动作。
按下面方法拆解：

1. **起始姿态**：确认这一镜开始时人物的姿势/表情/视线方向（这一步经常可以
   省略不写，因为就是关键帧本身的状态，写出来是为了防止模型"重新摆姿势"）。
2. **过程关键点（1-3 个动词短语）**：把动作拆成几个具体的中间点，不要用
   笼统形容词。
   - 差示例："她哭了"（模型不知道哭到什么程度、多快、动作细节）。
   - 好示例："眼眶先泛红，睫毛轻微颤动，随后一滴泪水缓缓滑落脸颊，嘴角
     随之向下撇，肩膀轻轻抽动一下"。
3. **结束姿态/定格**：明确结束时停在什么状态，配合"定格感"手法——关键
   情绪瞬间让画面在结束前有 0.5-1 秒的停顿，比如"最后定格于泪水滑落
   下巴的瞬间，人物保持低头姿态短暂静止"。

动作幅度和镜头分级要匹配：

- **A 级（对话/反应镜，全集主体）**：只写小幅度动作——转头、抬眼、嘴角
  变化、手指轻微动作、呼吸起伏。幅度越小越稳，出错率最低。
- **S 级（打斗/拥抱/痛哭/反转瞬间）**：才值得写大幅度动作，同时要接受
  这类镜头需要更多轮生成、更值得花预算精修。

## 第二步：运镜描述翻译成自然语言指令

复用 `short-drama-storyboard` 的 `shot_grammar.md` 运镜词汇，翻译成该平台
能理解的自然语言（大多数平台现在都支持中文自然语言描述运镜，不需要额外的
参数代码）：

| 分镜表运镜 | 图生视频提示词写法示例 |
|---|---|
| 推 | "镜头缓慢向前推进，聚焦人物面部" |
| 拉 | "镜头缓慢向后拉远，逐渐露出周围环境" |
| 摇（左/右/上/下） | "镜头缓慢向右摇镜，跟随人物视线转移" |
| 移 | "镜头随人物走动方向水平平移" |
| 跟 | "镜头跟随人物奔跑方向移动，略带手持晃动感增强代入感" |
| 固定 | 不写运镜描述，或明确写"镜头固定不动"防止模型自作主张加运镜 |

节奏副词按分级选：S 级用"骤然/猛烈/快速"强化冲击感，A 级用"缓慢/轻微/
自然"保持稳定不崩。

## 第三步：负面提示词模板

在正向提示词末尾（或该平台单独的负面提示词框）加上：

**通用负面（各平台通用）**：
```
避免：人物面部变形、五官错位、多余或缺失肢体、手指数量错误、肢体拉伸扭曲、
镜头剧烈抖动、画面闪烁跳变、人物中途换脸、模糊、低质量、水印、字幕、
多余人物入镜、色调突变
```

**短剧场景特有补充**（按需追加）：
- 涉及手部动作（拿东西、写字、鼓掌）：追加"手部动作清晰自然、手指数量
  正确"。
- 多人物同框：追加"人物之间不重叠穿模、位置关系保持稳定"。
- 特写镜头：追加"面部五官保持清晰不模糊、不出现第二张脸"。

## 完整示例

**A 级示例**（对话反应镜，克制幅度）：

> 起始画面为参考图中人物近景，人物眼眶先泛红，睫毛轻微颤动，随后缓慢低下
> 头，嘴角向下撇，肩膀轻微抽动一下，最后定格于低头沉默的姿态短暂停顿。
> 镜头固定不动，不加运镜。光线保持与参考图一致的柔和自然光。
> 避免：人物面部变形、五官错位、多余肢体、手指数量错误、镜头抖动、
> 画面闪烁、人物中途换脸、水印字幕。

**S 级示例**（反转瞬间，大幅度）：

> 起始画面为参考图中人物跪地伸手的瞬间，人物猛然抬头，眼神从震惊转为
> 坚定，随后迅速起身站直，衣摆随动作剧烈摆动，最后定格于挺直站立、
> 目光直视前方的姿态并短暂停顿 0.5 秒。镜头缓慢向前推进，聚焦人物面部
> 表情变化。避免：人物面部变形、五官错位、多余或缺失肢体、手指数量错误、
> 肢体拉伸扭曲、镜头剧烈抖动、人物中途换脸、水印字幕、多余人物入镜。

## 关于时长

图生视频平台普遍单次生成上限在 5-10 秒（个别到 15 秒），提示词里不需要
写具体秒数（多数平台是单独的时长参数，不是写进 prompt 文本），但动作分解
的"过程关键点"数量要和目标时长匹配——2-3 秒的短片段只写 1 个过程关键点，
5 秒以上才适合写 2-3 个关键点，写太多动作点挤进一个短时长里，模型会把
动作压缩变形。长动作怎么拆成多段见 `stability_playbook.md`。
