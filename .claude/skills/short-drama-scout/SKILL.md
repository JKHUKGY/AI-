# TikTok 短剧选题与生成助手 (short-drama-scout)

面向发布在 TikTok 的 AI 短剧项目：不再从网上抓取现成小说，而是由 Claude 直接原创
设计故事——可以自主选题，也可以按用户给的方向深化。产出可以直接交给下一步（分镜/
配音/AI 视频生成）使用的故事梗概 + 分集大纲。

## 目标平台特性（先想清楚再编）

TikTok 上的短剧内容和"网文改编长篇短剧"（单集 2-4 分钟那类长视频平台产品）不完
全一样，设计时要考虑：

- **竖屏 9:16**，观众划走成本极低，**每集前 3 秒必须有钩子**（冲突画面/爆炸性台
  词/悬念提问），不能铺垫。
- 单集时长建议 **60-180 秒**，比长视频平台的短剧集更短更快，一集只讲一个强反
  转/强情绪点，不堆多线。
- 结尾必须是**硬钩子**（cliffhanger）：一句话/一个画面把观众"钉"在下一集，常
  见手法见 `references/tiktok_trends.md`。
- 情绪浓度优先于逻辑严谨度：TikTok 观众要的是"爽感/意难平/猎奇"，人物动机要
  简单直接、可以一句话讲清楚。
- 当前热门题材、桥段套路、平台运营话术，参考 `references/tiktok_trends.md`——
  这份清单总结的是"题材套路"这个不受版权保护的创作层面，不是从任何具体版权作
  品扒下来的内容。清单可能过时，如果能联网，建议先用 WebSearch 搜一下"TikTok
  短剧 热门题材 当前年份"之类的关键词做交叉验证再定题材；搜不到就以清单为准。

## 两种创作模式

先判断这次是哪种模式（用户已经在请求里给了具体方向/大纲，直接进模式二；只是说
"帮我想个短剧"没给方向，走模式一；不确定就用 `AskUserQuestion` 问一句）：

**模式一：AI 自主选题**
用户没有指定方向。从 `references/tiktok_trends.md` 里挑 1-2 个当前热门题材做
交叉融合（比如"落魄千金归位" x "复仇黑化"），自己设计一个完整的原创故事。只
借鉴题材套路层面，人物姓名、具体情节、台词必须原创，不照抄任何已知影视剧/小说
的人物或桥段。

**模式二：按用户方向深化**
用户给了一个方向/大纲/关键词。这里按用户给的信息量分两种情况处理，核心区别在于
"缺的东西谁来补"：

- **一句话方向**（比如"落魄千金回亲生家庭逆袭"）：这只是核心骨架，人物关系、
  反转节奏、支线、具体人设台词都要由 Claude 结合 TikTok 节奏要求专业补全，
  不偏离用户给定的核心设定即可。
- **结构化选题大纲**（用户给的是"选题"层面的要点清单，而不是一句话，比如：
  题材/类型标签、核心卖点或爽点、目标观众、期望集数、参考同类题材、必须包含
  /避免的元素等，字段不必齐全）：这种情况下，Claude 要**自己生成一整套完整
  原创故事**——大纲里没写清楚的人物姓名、具体情节、台词、反转设计全部由
  Claude 原创设计补齐，只要不违背大纲里明确写出的要点。生成完之后，先用一段
  话向用户复述"我是这样理解并补全你的选题大纲的"，再往下走完整产出流程，方便
  用户在分集大纲展开前就能纠偏方向。
- 如果用户给的信息量已经很大（比如一篇完整原创故事/成稿大纲），可以直接跳到
  "评估节奏是否适合短剧 + 生成分集大纲"，不用重新编主线。

不确定用户给的算"一句话方向"还是"结构化选题大纲"不重要，处理方式是连续的——
信息给得越少，Claude 原创补全的比例就越高，两种情况都走下面同一套产出流程。

## 产出流程

1. **确定题材/方向**（见上）。
2. **故事骨架**：
   - 剧名（要有 TikTok 短剧标题的噱头感，比如带"离婚""亿万""马甲""打脸"
     这类高点击词）
   - 一句话逻辑线（log line）
   - 核心人物小传（男女主+反派+关键配角，性格用 1-2 个关键词概括，动机简单
     直接）
   - 整体大情节走向（起-承-转-合，标出全剧最大反转点大致在哪一集）
   - 贯穿全剧的悬念/情感钩子
3. **分集大纲**（默认 12-15 集，可由用户指定集数），每集包含：
   - 集标题（自带钩子/悬念感）
   - 开场 3 秒画面/台词（具体到镜头感，不是泛泛而谈）
   - 本集核心冲突（一句话讲清）
   - 结尾硬钩子（cliffhanger，具体台词或画面）
   - 建议时长（秒）
   - （可选）竖屏分镜要点：2-3 个关键镜头提示，供后续分镜/AI 视频生成参考；
     只给要点，不展开写完整分镜脚本或逐句台词——那是下一步单独的工作。
4. **TikTok 发布建议**：
   - 系列标题格式（如"《XXX》第 1 集｜……"）
   - 封面文字/开屏字幕建议（抓眼球短句）
   - 话题标签建议（结合题材给方向性建议，注明发布前需要在 TikTok 里核实当下
     实际有效的话题，不要编造不存在的热门标签当成事实）
   - 评论区/简介引导话术建议（比如引导追更、引导转发）

正式输出按 `references/output_template.md` 的结构组织，字段可以按故事实际情况
增减，不用死板套用。

## 内容合规红线

- **只做原创**：不使用任何现有影视剧/小说的人物姓名、专属台词或成段情节，避免
  抄袭/侵权风险。题材套路（比如"重生复仇""身世逆袭"）本身不受版权保护，可以
  自由使用；具体人物设定、情节编排、台词要原创设计。
- **遵守 TikTok 社区规范**：不写涉及未成年人不当内容、过度血腥暴力、色情擦边、
  自杀自残细节、真实政治人物/敏感政治议题、地域或群体歧视等内容——这些平台会
  限流甚至封号，也不利于长期做号。
- 如果用户主动要求加入上述红线内容，说明原因并建议替代处理方式，不要直接执行。

## 输出去向

默认直接在对话里给出 Markdown 格式的故事梗概 + 分集大纲。如果用户要求落盘保存，
写入项目下的 `output/<故事名>/outline.md`。这是原创内容，不涉及版权问题，可以
正常提交进仓库。
