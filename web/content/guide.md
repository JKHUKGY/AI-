# 使用指南：这套流程是怎么运作的

这个网站对应的是一整条"AI 短剧从选材到出片"的制作流水线。整条流水线由
Claude（AI）在后台一步步跑，你（剧本家）不需要碰终端、不需要懂提示词，
只需要在这个网站上看每一步的产出、提意见、或者直接改文字。

## 整体流程

1. **选材**：AI 从网上找有热度、适合改编成短剧的故事（这一步你一般看不到，
   是前期立项阶段的事）。
2. **分镜表（storyboard）**：AI 把故事拆成一集一集、一镜一镜的分镜表，
   同时写出人物形象和场景背景的设计提示词。**这是你最主要的工作区域**——
   台词对不对、节奏顺不顺、人物做的事符不符合人设，都在这一步的表格里看。
3. **人物 / 场景立绘（image-gen）**：AI 按照分镜表里的设计提示词，调用
   AI 出图工具，把每个角色、每个场景生成成图片。同一个角色/场景通常会
   生成好几张备选，需要你（或 AI）从中挑一张定为"基准图"，后面所有镜头
   都会照着这张图的样子来画。
4. **关键帧（keyframe-gen）**：AI 从每一集的分镜表里挑出真正关键的
   镜头（开场钩子、结尾悬念、情绪爆发点），把人物和场景的基准图合成到
   具体的分镜画面里，生成"这一镜大概长什么样"的静态预览图。
5. **视频（video-gen）**：把关键帧变成会动的视频。这一步**没有免费自动
   通道**——多数情况下需要人工把提示词提交到可灵/即梦等平台网页手动生成，
   或者是团队自己租显卡跑自建模型。所以这个网站在视频这一步只能帮你整理
   提交清单、记录你的意见，不能替你一键出片。

## 你在网站上能做的三件事，后果不一样

- **留言批注**：对某一镜、某张图、某一行视频任务写一句话意见，比如"这句
  台词感觉太生硬"。这是最安全的操作，不会改动任何文件，纯粹留痕，方便
  后续处理这一步的人（AI 或制作团队）看到。
- **直接改文字**：分镜表里的画面描述、台词、运镜等文字字段，你可以点开
  单元格直接改，改完点别处就自动保存进对应的文件。这个改动是真实生效的，
  会被下一步流程直接读取，所以确定要改的时候再动手，改错了可以再改回来。
- **点"重新生成"**：只有人物立绘、场景图、关键帧图这几类**图片**支持
  一键重新生成——网站会调用本机已经登录好的免费出图工具，通常 1-3
  分钟能出一张新图。**视频不支持一键重新生成**，视频页面的"请求重新
  生成"按钮只是把你的意见记下来，不会真的去生成，因为视频生成要么要人工
  提交、要么要花钱租显卡，不适合网页一键触发。

## 每个页面看什么

- **人物 / 场景**：每个角色/场景一个区块，上面是文字设计档案（外形、
  性格、服装、场景陈设），下面是已经生成的图片。点开一张图可以放大看、
  标记"入选"、留言，或者用"重新生成"重跑几张新的备选图。
- **分镜表（按集切换）**：整集的镜头表格，可以只看 S/A 级（最重要的
  关键镜头），逐格改文字、逐行留言。
- **关键帧（按集切换）**：这一集挑出来的关键镜头分别长什么样，同样可以
  放大看、标记入选、重新生成。
- **视频（按集切换）**：这一集每个镜头需要提交给视频生成平台的完整
  提示词清单，可以一键复制提示词、标记提交状态、已经生成好的视频文件会
  直接在页面上放出来预览。

## 常见问题

- **为什么有的镜头没有关键帧图？** 分镜表里标了"分级"，S/A 级是关键镜头
  才会生成关键帧图，B 级（次要过渡镜）和 C 级（复用素材/空镜）不需要
  单独出图，直接跳过是正常的。
- **为什么视频要手动提交？** 目前没有任何一家主流图生视频平台（可灵、
  即梦、Vidu 等）提供免费的统一接口，只能人工去网页操作；如果团队自己
  租显卡部署了开源模型，会走另一条单独的自动化通道，但那一步涉及真实的
  显卡费用，出于安全考虑不会在这个网页上被一键触发。
- **我改的字/提的意见什么时候会被处理？** 你的每一条留言、每一次文字
  修改、每一次重新生成请求都会被记下来，负责跟进这套流程的人（或者下次
  打开 Claude Code 时的 AI）会读到这些记录，决定接下来要怎么调整。
