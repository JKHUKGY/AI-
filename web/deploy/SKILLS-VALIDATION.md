# 制作 Skills 上线验收 · 2026-09-05

正式入口：<https://scriptwriter-jia.northcentralus.cloudapp.azure.com/#/skills>。选择有权限的项目后，可查看仓库 14 个 Skills 的版本、说明和源文档，提交加载自检及执行方案。关键帧提供 `user_choice` 与 `managed` 两种模式；H3 按既有决定停用，仅允许加载自检。

批准具体方案后，管理员可启动带工具的 Codex 执行。程序复制项目文字输入及 Skill 文件，以原图只读链接构造工作副本；在 `workspace-write` 沙盒中运行，不使用绕过选项。产物保存在项目的 `_web_state/skill_runs/<方案ID>/workspace/output/<项目>/`，结果链接从调用记录打开。运行超时 30 分钟；支持取消与服务重启后的中断记录。工作副本的结果不会自动覆盖正式项目。

普通账号可调用规划与加载自检；带工具的通用执行目前限管理员。租卡与新的计费视频任务需通过网站已有入口处理。本次没有验证完整出图筛选、逐图选择回写或 GPU 视频生成闭环，不能据此宣称这些媒体流程已通过端到端验收。
