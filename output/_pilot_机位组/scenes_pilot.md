# 场景机位组 —— 试点样例（新格式的 scenes.md 长什么样）

这份文件是 2026-09「场景机位组」机制的**跨机位一致性试点**，同时充当新
`scene_prompt_template.md` 格式的一个填好的样例。不属于任何一部剧。

试点要回答的问题只有一个：**同一个房间从不同角度生成，会不会生成成"几个不同的
房间"？** 如果会，这条路就不通，得改成"A 出得更宽 + 下游裁切/局部重绘造机位"。

- 场景编号/名称：PILOT_餐厅
- 出现集数：（试点，无）
- 室内/室外：室内
- 时间/天气：夜，室内灯光为主
- 氛围/情绪关键词：奢华冷漠、阶层压迫感
- 关键陈设/构图元素：黑色大理石长餐桌、多层水晶吊灯、通往厨房的门洞、
  暖黄台灯 + 深色边柜、纵深端落地窗
- 光影/色调设定：吊灯暖黄主光 + 落地窗外冷色夜光，冷暖对比
- **场景重要度**：主场景（试点按主场景走，验证完整流程）
- **机位组**：`A主机位` + `B反打` + `C侧机位`（`D细节` 本次不测）

### 空间关系（**看过 A 主机位的实际出图之后**填的，不是凭 prompt 想象）

依据：`PILOT_餐厅_A主机位/PILOT_餐厅_A主机位_00.png`

```
- 主轴（A 机位的视线方向）：从餐厅入口朝向纵深端的落地窗，长餐桌的长边方向
  与主轴一致（桌子朝画面深处延伸）
- 出入口/窗（相对 A 机位画面）：通往厨房的门洞在**画面右侧**（门洞里能看到
  冷色调的厨房台面和水槽）；落地窗在**画面纵深端正中**，窗外是夜色和树影；
  餐厅入口在**画面外、相机身后**
- 主要家具及朝向：黑色大理石长餐桌居中纵向摆放，两侧各四把深灰皮质餐椅，
  近端（靠相机这头）还有一把餐椅背对镜头；多层水晶吊灯悬在桌面正上方；
  桌面中央一盆白色花艺
- 次要陈设：**画面左侧**靠墙一张深色边柜，柜上一盏暖黄灯罩台灯 + 一盆绿植，
  边柜后方墙面是深蓝黑大理石；地面是米白抛光大理石配深色大理石镶边条；
  吊顶是叠级造型带暖色灯槽
- 人物默认站位（供后续分镜用）：主位在纵深端（靠落地窗那头），佣人从画面
  右侧的厨房门洞进出
- 各机位相对 A：
  · B反打  = 从落地窗那端朝餐厅入口方向回看，同机高
  · C侧机位 = 从 A 位置右转 90°、移到长桌右侧长边旁，同机高
  · D细节  = 桌面高度俯 30°（本次未生成）
```

**注意这段里"厨房门洞在画面右侧、台灯在画面左侧"是核对过出图的**——prompt 里
是这么要求的，出图也确实这么给了。如果模型把它们放反了，这里就要按图里的实际
情况写，因为下游的越轴判断依赖的是**图**，不是 prompt 的原意。

## 试点结论

**这个试点本身没有跑完（只出了 `A主机位` 三张，`jobs_BC.json` 里的 B/C 一直没提交），
但它要回答的问题已经在真实项目上得到答案了** —— 2026-09-02 做《出狱后我成为了非洲矿王》
ep03 时，直接在两个真实场景上按同一套方法出了 6 个派生机位，结论比这个试点更有说服力
（真实陈设更复杂、跨机位要保持一致的物件更多）。

### 结论：**跨机位一致性可行，6/6 全部成功。这条路通，不需要退回"A 出得更宽 + 下游裁切"。**

证据（逐张 Read 对答案，详细判据记在
`output/出狱后我成为了非洲矿王/assets/selected.md` 的场景基准图表里）：

### 三条硬要求各自的实际贡献（这是这次最有用的发现）

1. **`ref_images` 传 A 的选中图**：决定性。6/6 都保住了"是同一个房间"，没有出现
   《千金归位》SC06 那种"非同一栋房子"的漂移。
2. **点名要一致的具体物件**（"同一盏多层水晶吊灯、同一批深灰皮质餐椅"）：有效。
   凡是被点名的物件，6 张图里没有一件换了样式。
3. **点名左右关系的翻转**：**这条最容易被低估，实际效果最好**。两个 `B反打` 的
   左右翻转全部一次命中（客厅的电视墙、板房的办公桌+矮柜+日光灯管），说明模型确实
   在按这句指令重排空间，不是碰巧。

### 一个必须记住的偏差

`SC03_C侧机位` 出的不是严格的"右转 90°"，而是约 45° 的侧前方机位。**这不是失败**
（房间一致性全部满足、构图更好用），但它说明：**机位的角度值是"大致要求"，具体给多少度
由模型决定，所以「空间关系」块必须在出图之后按图回填，不能照抄 prompt 的措辞。**
这正是 `scene_prompt_template.md` 第三节强调"必须用 Read 打开看一遍再填"的原因，
这次实地撞到了。

### 这个试点目录怎么处理

保留作为格式样例（新版 `scenes.md` 长什么样），但**结论以上表为准**，
`jobs_BC.json` 不必再补跑——真实项目上的 6 张证据强于这个空场景试点。
