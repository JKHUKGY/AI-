# 场景机位组 —— 试点样例（新格式的 scenes.md 长什么样）

这份文件是 2026-09「场景机位组」机制的**跨机位一致性试点**，同时充当新
`scene_prompt_template.md` 格式的一个填好的样例。不属于任何一部剧。

试点要回答的问题只有一个：**同一个房间从不同角度生成，会不会生成成"几个不同的
房间"？** 如果会，这条路就不通，得改成"A 出得更宽 + 下游裁切/局部重绘造机位"。

## PILOT 奢华别墅餐厅

- 场景编号/名称：PILOT_餐厅
- 出现集数：（试点，无）
- 室内/室外：室内
- 时间/天气：夜，室内灯光为主
- 氛围/情绪关键词：奢华冷漠、阶层压迫感
- 关键陈设/构图元素：黑色大理石长餐桌、多层水晶吊灯、通往厨房的门洞、
  暖黄台灯 + 深色边柜、纵深端落地窗
- 光影/色调设定：吊灯暖黄主光 + 落地窗外冷色夜光，冷暖对比
- **场景重要度**：主场景（试点按主场景走，验证完整流程）
- **机位组**：`A主机位` + `B反打` + `C侧机位`（`D细节` 本次不测）

### 空间关系（**看过 A 主机位的实际出图之后**填的，不是凭 prompt 想象）

依据：`PILOT_餐厅_A主机位/PILOT_餐厅_A主机位_00.png`

```
- 主轴（A 机位的视线方向）：从餐厅入口朝向纵深端的落地窗，长餐桌的长边方向
  与主轴一致（桌子朝画面深处延伸）
- 出入口/窗（相对 A 机位画面）：通往厨房的门洞在**画面右侧**（门洞里能看到
  冷色调的厨房台面和水槽）；落地窗在**画面纵深端正中**，窗外是夜色和树影；
  餐厅入口在**画面外、相机身后**
- 主要家具及朝向：黑色大理石长餐桌居中纵向摆放，两侧各四把深灰皮质餐椅，
  近端（靠相机这头）还有一把餐椅背对镜头；多层水晶吊灯悬在桌面正上方；
  桌面中央一盆白色花艺
- 次要陈设：**画面左侧**靠墙一张深色边柜，柜上一盏暖黄灯罩台灯 + 一盆绿植，
  边柜后方墙面是深蓝黑大理石；地面是米白抛光大理石配深色大理石镶边条；
  吊顶是叠级造型带暖色灯槽
- 人物默认站位（供后续分镜用）：主位在纵深端（靠落地窗那头），佣人从画面
  右侧的厨房门洞进出
- 各机位相对 A：
  · B反打  = 从落地窗那端朝餐厅入口方向回看，同机高
  · C侧机位 = 从 A 位置右转 90°、移到长桌右侧长边旁，同机高
  · D细节  = 桌面高度俯 30°（本次未生成）
```

**注意这段里"厨房门洞在画面右侧、台灯在画面左侧"是核对过出图的**——prompt 里
是这么要求的，出图也确实这么给了。如果模型把它们放反了，这里就要按图里的实际
情况写，因为下游的越轴判断依赖的是**图**，不是 prompt 的原意。

### 提示词正文

#### `A主机位`（无参考图）

见 `jobs_A.json`。要点：`【机位】定场主机位：相机架在餐厅入口处、齐眼高约1.5米、
正对长桌的纵深方向，广角收全，画面必须同时看清房间的出入口、窗户和主要家具的
相对位置关系。`

#### `B反打` / `C侧机位`（`ref_images` = A 的选中图）

见 `jobs_BC.json`。两条都按模板的三条硬要求写了：

1. **点名要一致的具体物件**：同一盏多层水晶吊灯、同一张黑色大理石长餐桌、
   同一批深灰皮质餐椅、同样的米白抛光大理石地面配深色镶边条。
2. **点名左右关系的翻转**（只有 B 需要）：`从这个反打机位看，通往厨房的门洞
   现在在画面左侧（参考图1里它在右侧），带暖黄灯罩的台灯和深色边柜现在在
   画面右侧（参考图1里它在左侧）`。
3. **写清这个角度新露出来的东西**：B 是"餐厅的入口和玄关方向，可见通往客厅的
   开口"（A 机位里这是相机身后）；C 是"长桌对面那一侧的完整墙面，以及台灯和
   边柜的正侧面"。
