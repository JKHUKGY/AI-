# 《出狱后我成为了非洲矿王》场景/背景设计提示词

## 画风锚点（全剧统一，与角色提示词共用同一句）

> 非洲现代都市与矿业实景写实照片级质感，纪录片式自然光结合硬光源打光，
> 竖屏 9:16 构图安全区设计，暖黄高饱和的非洲日光色调（豪宅室内场景转为
> 冷色调奢靡灯光形成对比），高细节皮肤/服装/尘土质感，无水印无文字，
> 避免卡通化、避免五官比例失真

## SC01 非洲监狱门口

- 出现集数：第1集(1-1)
- 室内/室外：室外
- 时间/天气：日，晴，烈日
- 氛围/情绪关键词：压抑释然、粗粝写实
- 关键陈设/构图元素：锈迹斑斑的铁栅栏大门、灰白水泥围墙、门口停靠的越野车、
  远处荒芜的黄土地
- 光影/色调设定：正午硬光，高对比阴影，土黄色调为主
- 会用到的镜头/集数：1-1全部镜头

### 提示词正文
```
[画风锚点] + 室外场景，非洲乡镇简陋监狱大门，锈迹斑斑的铁栅栏门、灰白
水泥围墙，门口停着一辆灰尘覆盖的越野车，远处是荒芜的黄土地和稀疏灌木，
正午烈日硬光、高对比阴影，土黄色调，无人物，空镜头/场景原画，
高细节，8k画质
```

## SC03 顾家别墅客厅

- 出现集数：第1集(1-3)、第3集(3-1)、第6集(6-1)、第8集(8-2)、第9集(9-1/9-3)、
  第10集(10-1)
- 室内/室外：室内
- 时间/天气：日，室内灯光为主
- 氛围/情绪关键词：奢华冷漠、阶层压迫感
- 关键陈设/构图元素：挑空天花板、真皮沙发、大理石地面、水晶吊灯、落地窗
  外可见泳池
- 光影/色调设定：冷色调室内灯光叠加自然光，与角色的暖肤色形成冷暖对比，
  强化"格格不入"的疏离感
- 会用到的镜头/集数：见上，本场景为全剧最高频复用场景，建议一次性生成
  2-3 个机位角度（正面全景、沙发区中景、挑空楼梯俯瞰角度）供后续所有集数
  复用

### 提示词正文
```
[画风锚点] + 室内场景，非洲豪华别墅挑空客厅，真皮沙发、大理石地面、
水晶吊灯、落地窗外可见泳池，冷色调室内灯光与自然光混合，奢华但冷漠的
氛围，无人物，空镜头/场景原画，高细节，8k画质
```

## SC05 顾家客房

- 出现集数：第1集(1-3)、第2集(2-2)
- 室内/室外：室内
- 时间/天气：日/晚均有使用（1-3为日间，2-2为夜晚，光影按对应集数微调）
- 氛围/情绪关键词：局促简朴、母子相依的温情孤岛
- 关键陈设/构图元素：单人床、旧书桌、行李箱、窗户（夜晚可见虫鸣暗示的窗外

  鲜明对比，是全剧唯一"温暖"的角落
- 会用到的镜头/集数：1-3后半段、2-2全部镜头

### 提示词正文
```
[画风锚点] + 室内场景，简朴狭小的客房，单人床、旧书桌、一只半旧行李箱，
窗边一盏暖黄台灯，陈设简单朴素，与豪宅其他房间形成对比，无人物，
空镜头/场景原画，高细节，8k画质
```

## SC06 矿场办公室

- 出现集数：第3集(3-2)、第7集(7-3，夜晚栽赃场景，光影需切换为夜版)、
  第8集(8-1，即会议室，见SC07)
- 室内/室外：室内
- 时间/天气：日为主，第7-3为夜晚栽赃场景需单独标注夜版
- 氛围/情绪关键词：简陋务实的专业感
- 关键陈设/构图元素：板房结构、墙上挂满地质地图、桌上堆着岩芯样本、
  江砚的办公桌（含下层抽屉，栽赃道具的关键位置）
- 光影/色调设定：日间为顶棚漏光的自然光，粗粝感；夜晚版本仅手电/顶灯冷光，
  阴影浓重、氛围紧张
- 会用到的镜头/集数：3-2（日版）、7-3（夜版，需重点突出办公桌下层抽屉的
  构图位置）

### 提示词正文（日版）
```
[画风锚点] + 室内场景，简陋的矿场板房办公室，墙上挂满地质地图，桌上堆着
厚厚的岩芯样本，一张带下层抽屉的旧办公桌，自然光透过顶棚缝隙洒入，
粗粝务实的氛围，无人物，空镜头/场景原画，高细节，8k画质
```

### 提示词正文（夜版）
```
[画风锚点] + 室内场景，同一间矿场板房办公室，夜晚，仅顶灯冷光照明，
阴影浓重，墙上地质地图在暗处若隐若现，重点突出一张办公桌的下层抽屉，
紧张诡秘的氛围，无人物，空镜头/场景原画，高细节，8k画质
```

## 复用建议

- SC03（顾家别墅客厅）跨6集复用，务必第一次生成时就做出2-3个机位角度，
  避免后续集数发现"这个角度没生成过"临时补图。
- SC06 矿场办公室日/夜两版共用同一空间陈设，只调整光源和局部构图重点
  （夜版聚焦办公桌抽屉），不要当成两个完全不同的场景重新设计陈设。
- SC08/SC09/SC10（丛林/营地/开采面）均只在第4、7集各出现一次，属于低频
  场景，优先级可排在SC03等高频场景之后生成。
