# 《出狱后我成为了非洲矿王》人物形象设计提示词

## 画风锚点（全剧统一，写在每个角色提示词最前面）

> 非洲现代都市与矿业实景写实照片级质感，纪录片式自然光结合硬光源打光，
> 竖屏 9:16 构图安全区设计，暖黄高饱和的非洲日光色调（豪宅室内场景转为
> 冷色调奢靡灯光形成对比），高细节皮肤/服装/尘土质感，无水印无文字，
> 避免卡通化、避免五官比例失真、避免种族刻板化丑化表现

## 1. 江砚（男主）

### 角色档案
- 首次登场集数：第1集
- 年龄/性别：25岁左右，男
- 身高体态：183cm左右，偏瘦但肩背线条结实，长期野外勘探练出的紧实体格
- 发型发色：黑色短发，寸头略长，不刻意打理但干净利落
- 瞳色：深棕近黑
- 肤色：小麦色，长期户外作业带有晒痕
- 气质关键词：内敛稳重→挺拔站姿、下颌线条紧绷、目光沉稳不闪躲；专业冷静→
  说话时习惯先蹙眉思考、手指无意识摩挲下巴；隐忍中带锋利→平静表情下眼神
  偶尔骤然变冷

### 造型分表
- 造型名称：出狱/寄人篱下期（第1-9集）
  - 服装描述：洗得发白的浅色衬衫或深色速干T恤，卡其色工装长裤，磨损的登山鞋，
    整体朴素干练，无配饰
  - 配饰/道具：手腕一块廉价电子表，随身背一个半旧登山包
- 造型名称：创业翻身期（第10集起）
  - 服装描述：合身的浅卡其色野外工装夹克或简洁商务休闲装，质感明显提升但
    依旧不浮夸，符合"专业矿业人士"人设
  - 配饰/道具：换成金属表带手表，随身携带勘探平板/文件夹

### 提示词正文
```
[画风锚点] + 一名25岁左右的东亚男性，黑色短寸头，深棕色瞳孔，小麦色带晒痕
的皮肤，身形偏瘦但肩背结实，穿着洗得发白的浅色衬衫、卡其色工装长裤，
神情内敛沉稳、目光专注不闪躲，站姿挺拔，正面全身像，干净背景，
角色设计参考图/角色立绘，高细节，8k画质
```

### 需要一次性生成的差分
- 正面立绘（出狱/寄人篱下期，默认沉稳表情）
- 正面立绘（创业翻身期造型）
- 侧面/背面（用于转身图）
- 表情差分·中性专业（勘探时蹙眉观察）
- 表情差分·隐忍冷静（被顾家羞辱时攥紧拳头、面无表情）
- 表情差分·审视锐利（识破陷害瞬间，眼神骤冷）
- 表情差分·坚定决绝（明牌决裂时的平静而不容置疑）

### 反面提示词
避免：多余肢体、手指数量错误、五官崩坏、水印文字、镜像不对称、风格与其他
角色不统一、过度健美的健身房身材（应是野外劳作的精瘦结实而非健身房肌肉）

## 2. 苏慧（女配，江砚母亲）

### 角色档案
- 首次登场集数：第1集
- 年龄/性别：45岁左右，女
- 身高体态：偏瘦小，常年操劳显得比实际年龄苍老
- 发型发色：黑发夹杂明显白发，简单扎成低马尾或盘发
- 瞳色：深棕
- 肤色：被非洲日晒晒得黝黑，手部粗糙有老茧
- 气质关键词：温柔隐忍→低头含胸的习惯性姿态、说话时先赔笑；软弱委曲求全→
  被训斥时下意识后退半步、绞手指；护子心切→提到儿子时眼神瞬间柔软坚定

### 造型分表
- 造型名称：顾家佣人期（第1-9集）
  - 服装描述：洗得发白的旧布裙或围裙，颜色暗淡，鞋子是磨损的布鞋，无任何
    首饰
  - 配饰/道具：常年系着的围裙、手上常端着家务用具
- 造型名称：苦尽甘来期（第10集起，故事结局阶段）
  - 服装描述：干净得体的素色棉麻衣裙，气色明显好转，不奢华但整洁体面

### 提示词正文
```
[画风锚点] + 一名45岁左右的东亚中年女性，黑发夹杂白发低马尾，深棕色瞳孔，
皮肤被日晒晒得黝黑，身形偏瘦小，常年操劳的疲惫气质，穿着洗得发白的旧布裙、
系着围裙，神情温和隐忍、微微低头含胸的姿态，正面全身像，干净背景，
角色设计参考图/角色立绘，高细节，8k画质
```

### 需要一次性生成的差分
- 正面立绘（顾家佣人期）
- 正面立绘（苦尽甘来期造型）
- 表情差分·强笑隐忍（被羞辱时赔笑）
- 表情差分·心疼泛泪（看着儿子受委屈）
- 表情差分·崩溃下跪（第8-9集下跪求情）

### 反面提示词
避免：多余肢体、手指数量错误、五官崩坏、水印文字、过度苍老或过度年轻化、
风格与其他角色不统一
