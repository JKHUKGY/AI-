## 验收说明

逐张 Read 核对：
- 人物面部特征/发型/服装与 `assets/selected.md` 里对应的基准图保持一致
  （江砚、苏慧、顾万通、刘兰、顾浩、顾瑶均逐张核对同一张脸/同一套服装）。
  镜1（开场3秒钩子，4人群戏）首轮 `_00` 因光线较暗导致刘兰/顾浩发色与基准图
  有偏差，改选同一批次里一致性更好的 `_01` 版本。
- 画面还原了分镜表"画面描述"列的关键动作/情绪节点（镜6的拉手臂质问、镜11的
  背对抹泪、镜12的攥拳、镜18的攥拳目送）。
- 场景背景与SC04（暖黄餐厅灯光+冷调奢靡氛围）/SC05（夜晚暖黄台灯客房）基准图
  一致，日夜版本没有混用。
- 竖屏9:16构图、无水印文字、画风统一为写实照片级质感，符合 `style_bible.md`。
- 多人物镜头（镜1、镜6、镜7、镜8、镜10、镜13、镜14）位置关系合理，无人物
  重叠/贴脸问题。

## 生成过程记录

- 首轮 `--parallel 3` 批量生成时 Codex 出图后端（`gpt-5.6-sol`）出现大范围
  "model is at capacity" 限流，多数任务失败；改用 `--parallel 1`（降低并发）
  分两轮补齐，最终18镜全部至少出到1张可用图，其中镜6（核心冲突S级镜）经过
  一次专门的3连拍重试才补齐（此前两轮共4次尝试全部因限流失败）。
- 本次共调用生成 API 约 60+ 次（含失败重试），最终产出 18 镜全部关键帧，
  其中新生成 18 镜、复用已有素材 0 镜（`storyboard/ep02.md` 备注列本集
  无标注复用的镜头）。
