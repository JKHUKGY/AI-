震惊，未达到需要重新生成的门槛（不是核心最高优先级镜头，且下方仍能读出
情绪转折），先入选；如果实际剪辑发现这一镜情绪不够跳，可以单独针对这一镜
再来一轮，prompt 里加强"瞳孔骤缩、呼吸一滞"这类更具体的震惊描述。

## 脚本修复记录（重要）

本集生成过程中发现 `generate_images.py`（`short-drama-image-gen` 的共享脚本）
有一个之前从未触发过的 bug：`codex exec` 的 `-i/--image` 是 clap 的多值选项
（`<FILE>...`），脚本原先把 prompt 文本直接追加在 `-i` 参数列表之后，导致
prompt 被贪婪解析成"又一张图片路径"，真正的 PROMPT 位置参数落空，codex
转而尝试从 stdin 读取，进而报错退出。这个 bug 只在传了 `ref_images`（本地
出角色/场景基准图时都是纯文生图、没传参考图）时才会触发，所以之前
`short-drama-image-gen` 阶段的 45 次调用全部正常，直到这次关键帧合成第一次
使用 `ref_images` 才暴露。已在脚本里用 `--` 显式截断选项解析修复，之后
`short-drama-video-gen` 等下游 skill 复用这个脚本时不会再遇到同样的问题。
