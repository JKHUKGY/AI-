# 关键帧验收清单（阶段二用）

沿用 `short-drama-image-gen` 里的通用出图验收标准（角色一致性、五官肢体、
构图安全区、水印、画风统一），在此基础上关键帧还要多核对下面这些**镜头
专属**的标准。

验收的依据有两份，分工不能混：

- **情节对不对** → 看卡的 `script_ref_zh`（剧本原文锚点）。
  **不要拿分镜表「画面描述」列或装配出的提示词当验收标准**——那是这一轮
  生成的输入，拿它判卷等于自己出题自己判卷。
- **画面做没做到设计** → 看阶段一那份 `keyframe_prompts_ep0X.md`
  的走位表（这是人已经确认过的设计，图必须还原它）。

## 判定与执行规则

先读 [review_quality.md](review_quality.md)：下列逐项检查按实质影响分critical／major／minor，合理画外或证据不足记unconfirmed；普通约数的小偏差不自动fail。剧情看原文，画面实现看批准卡；分别判断起点和完成动作。每张新图仍实际独立查看，未变参考和已完成整场复核可复用。

不合格后是否再生成由 [generation_modes.md](generation_modes.md) 决定：托管自动最小修正，用户选择先展示方案等决定；用户明确采用可保留failed图，原判定不改。下面“重出／不可用”指技术判断及建议，不覆盖模式和三轮上限。

## 一、走位/朝向/纵深（2026-09 新增，上一版翻车最多的地方）

对照审阅表里这一镜的走位表逐人核对：

- **每个人的 `camera_relation` 有没有做到**：写 `three_quarter_back`
  （过肩）的人，图里是不是真的只看到后脑+一点脸颊轮廓？写 `profile` 的是不是
  真的整个侧面？——模型最爱做的事就是把人悄悄转成正脸。
- **有没有变成"合影"**：几个人是不是都平着脸朝镜头、彼此没有视线关系？
  这是判不可用的硬条件，不是"可以将就"。参照失败样本
  `output/出狱后我成为了非洲矿王/keyframes/ep03/ep03_镜10/ep03_镜10_00.png`。
- **纵深层次有没有做出来**：`near` 的人是不是明显更大、更靠画面下缘？
  三个人是不是被摆成了同一条横线？
- **视线连不连得起来**：A 看 B，B 的位置在不在 A 的视线方向上？
  刻意的不对视（一人看人、一人看地）有没有做出来，而不是两人都在看空气？
- **`pos_x` 左右有没有对**：和审阅表一致，且和「机位」列 + `scenes.md`
  的四向速记一致。

## 二、景别与裁切

- **景别对不对**：分镜表标"特写"、图出成全身远景，就算人物场景都对也判
  不可用——竖屏短剧里景别本身就是叙事语言。
- **是不是又漂回底板的取景范围**：这是上一版最常见的故障——标中景、出全景，
  人物只占画幅一半高，画面下方 40% 是空地板。核对 `crop_zh` 说的裁切线：
  底边该切在大腿/膝盖上方的，图里有没有连脚带地板一起给出来？
- **地面/天花的占比**有没有按 `plate_crop_zh` 裁掉。

## 三、人物与场景一致性

- **同一张脸、同一套服装**：合成镜头最容易出问题的地方——模型会在"融入
  场景"时悄悄改人物长相或服装细节，必须逐张核对基准图。
- **场景背景与该 SC 编号、该机位的底板一致**（陈设、光影、日夜版本、
  以及**这个机位该看到的东西**）。注意这条查的是"和**本镜指定的那张机位
  底板**一致"，不是"和这个场景的某一张图一致"——真正的反打角度不该被
  这条判不合格。
- **跨机位一致性**：同一场景的几张机位底板之间是不是同一个房间？
  吊灯/主要家具/地面材质/墙面材质/光源位置是不是同一套。已有同类故障可以
  当先验：`output/千金归位/assets/selected.md` 记录"SC06 车道日/夜版建筑
  外观不一致：夜版是欧式石材豪宅，日版是现代极简风建筑，非同一栋房子"
  ——那还只是换光影就漂了。漂了就重出，别将就。
- **越轴检查**：同一个人在一组正反打的两镜里，画面左右位置必须**正好
  相反**；如果一样，观众会觉得两人突然对调了位置。脚本在阶段一已经拦过一遍，
  这里核对图有没有真的按卡来。

## 三点五、场次级验收：把一场戏的图排开一起看（2026-09-04 新增）

**这一条和上面所有条的区别是：它不是逐张看，是一场戏的图全部出完之后，
按镜号平铺在一起看。**

理由很硬：**逐张看永远抓不到连戏问题。** 一张图里沙发是空的，单看没有任何
毛病——只有把它和前一镜并排放在一起，才看得出"上一镜那两个人去哪了"。
《出狱后》v2 ep01 场次 1-3 九张图逐张都验收通过了，剪在一起才发现沙发上的
两个人在其中三镜里凭空消失。

一场戏的图排开之后，逐条问：

1. **有没有人凭空消失或凭空出现？** 拿 `scene_beats[].present` 对着看：
   在场的每个人，在每一镜里要么看得见、要么有理由看不见。
   审阅表里那张「在场核对表」就是给这一步用的。
2. **道具有没有变样？** 同一只行李箱在这一场的每一镜里是不是同一只
   （颜色、材质、拉杆、滚轮）？同一只包是拎着还是背着？
   —— ep01 第一轮：行李箱在镜30 变成棕色旧皮箱、登山包在镜21 跳到了肩上。
3. **光有没有跳？** 同一场戏同一时刻，光的方向和色温在每一镜里应该一致。
   （卡上同一场的 `light_zh` 本来就该一字不改地复用。）
4. **房间还是同一个房间吗？** 跨机位看：同一件家具、同一面墙、同一盏灯
   在不同机位下是不是同一个东西？左右关系有没有按机位翻转？
5. **人物的服装/发型在这一场里有没有变？**

一场选定后完整检查一次；仅一镜替换时只复核新图和受影响的邻接关系，保留其余检查结论。

有场次主帧的场次，多一条最省事的核对方式：**把主帧和这一场每一镜并排看**
——主帧就是这一场的标准答案。

不通过时，问题多半在 `scene_beats` 那一层（`present` 漏人、`state_zh` 没写
死道具外观），改那里再重出，不要一镜一镜打补丁。

## 四、其他

- **多人物镜头的空间关系是否合理**：对峙戏两人要有距离和眼神朝向关系，
  不要出现人物重叠、姿态诡异贴在一起。
- **道具在不在、位置对不对**（`props_zh` 里写的东西）。道具连续性很容易在
  这一步整条丢掉：镜1、镜2 才刚把公文包摔在沙发上，上一版 `ep03_镜03`
  那条 prompt 里**一个字都没提这只包**，图里自然也没有——所以它现在是卡上
  一个独立的 `props_zh` 条目，而不是指望从画面描述里顺带带出来。
- **本镜如果是全集最高优先级镜头**（开场钩子/结尾钩子），标准要更严格，
  优先指出影响钩子的实质缺陷，并在模式允许和剩余预算内优先处理；不能增加第四轮或跳过用户选择。

## 不合格的处理

**改卡，不改 prompt。** 把问题落到具体字段上再重跑
`build_keyframe_prompt.py`：

| 症状 | 改哪个字段 |
|---|---|
| 该过肩的人给了正脸 | 那个人的 `camera_relation`（并检查 `body_dir` 是否自洽） |
| 几个人拍平成一排 | `depth` 分层；必要时把某人挪到 `near` 当前景 |
| 标中景出全景、地板太多 | `subject_frac` 调高 + `crop_zh` 写死裁切线 + `plate_crop_zh` 写狠一点 |
| 背景变成另一个房间/另一个角度 | 先查 `plate_image` 是不是传错了机位（改文字没用） |
| 人物长相/服装漂了 | 换一张更贴的 `ref_images`（比如换成侧面转身那张） |
| 视线看空气 | `gaze_at` + 对手的 `pos_x` |
| 道具丢了 | `props_zh` 单独成条，写清在画面哪个位置压在什么上面 |
| **上一镜在场的人这一镜不见了** | 把他写进 `background_people[]`（带参考图或 `appearance_zh`）；确实看不见就写进 `present_off_frame[]` 表态 |
| **画面里的沙发/餐桌是空的** | 同上。空家具几乎总是"忘了写坐在上面的人" |
| **道具在这一场里变了样** | 写进 `scene_beats[].state_zh`，让这一场每一镜都重复一遍它的外观 |
| **标近景/特写却出成另一个机位的画面** | 查 `plate_id` 是不是宽底板——近景/特写要挂 `_紧` 的紧底板，改文字没用 |

单镜最多三轮，每轮最多1／2／3张；可提前达标或因无改进停止。用户选择模式每个修正方案均由用户决定是否执行；托管模式依授权自动执行。到限附最佳候选和差异，不再生成。明确用户采用时登记selected_by_user，技术fail仍保留。
