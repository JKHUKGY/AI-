# 《出狱后我成为了非洲矿王》v3 —— 立项与差异说明

> 2026-09-05 立项。剧本来源：仓库根目录 `《出狱后我成为了非洲矿王》一卡.docx`
> —— **10 集 / 23 场 / 11,325 字**（用修正后的 docx 解析重新提取，
> 全文落在 `storyboard/script_source.txt`，后面所有「剧本原文锚点」都从它抄）。

## 为什么要有第三版

v2 不是做坏了——它的**画风锚点、人设、机位组底板都是对的，81 张素材 0 返工**。
问题是 v2 是用 **2026-09-03 那一版 skill 规则**做的，而 09-04/09-05 这两天
从 v2 的实拍结果里挖出了四个**结构性**缺陷，并且已经改进了 skill。
这些改进**没法靠打补丁装回 v2**（我试过两天，一直在返工），所以重开一版。

### v3 相对 v2 的四处结构性改动

| # | 改什么 | v2 的病是怎么暴露的 |
|---|---|---|
| 1 | **分镜表加「在场人物」列**，和「出场人物」分开 | v2 只有「出场人物」= 这一镜要演的人，**没有字段承载"画面里还应该看得见谁"**。ep01 场次 1-3 四个人全程在客厅，九镜里五镜画面中有那张沙发、卡上一个字没写沙发上的两个人 → 三镜出成**空沙发**（`ep01_镜25`） |
| 2 | **场景底板加「焦段」维度**：每个机位分宽底板 + `_紧` 紧底板 | v2 的 ep01 **35 镜里 22 镜是近景/特写**，却全挂在宽景定场底板上。底板里没有那个距离的像素，"推近 2.1 倍"只能让模型**重新合成一个相机**——一旦重新合成，"保持场景一致"就整体失效（`ep01_镜24` 标着 A主机位、出来是个全新机位） |
| 3 | **场次节拍 `scene_beats` + 场次主帧**，在分镜阶段就划好 | v2 每一张关键帧都是从**空场景底板 + 角色三视图**合成的，等于每一镜重新把人搬进空房间一次。道具外观、谁在场、光线全靠每张卡手抄 → 行李箱变棕皮箱、登山包跳到肩上、虚焦人影变成一男一女 |
| 4 | **机位选择先过几何校验** | ep06 初稿把四镜排成 `C侧机位`，而那面圆镜在**西墙**、C 是朝东拍的——要求画面里出现两个站在**相机背后**的人。`scenes.md` 的「四向速记」本来就写着答案，但没人回头对 |

### 不改的（v2 已经验证过，照搬）

- **画风锚点**：v2 那句已经是干净的（没有 `8k`/`高细节` 这类质量咒），继续一字不改地用。
  **中途改锚点会让新旧素材画风对不上**，这是硬纪律。
- **写实照片质感**这个风格结论，以及三条理由（贴合故事 / 平台热度 / 非洲矿业实景靠材质说服力）。
- **角色纯色背景三视图**当 canonical 锚点；绝不拿上一镜的产出当下一镜的参考图。
- **人设档案 `characters.md`**、**场景档案 `scenes.md` 的陈设与空间关系块**。

## 素材怎么办：复用 v2，不重跑

**v2 的 81 张素材（8 个角色三视图 + 19 张机位底板）在 v3 里直接复用。**

理由：画风锚点一字未改，重跑只会得到同一套东西的另一批 seed 变体，
纯烧额度。`assets/` 下用**软链接或路径引用**指向 v2 的文件，
`selected.md` 里注明来源。

**v3 真正要新出的素材**（v2 缺的）：

| 类别 | 缺什么 | 数量估计 |
|---|---|---|
| 紧底板 | v2 只有 7 张（而且是我这两天补的）。**每个真的有近景/特写落上去的机位都要一张** | 按 10 集分镜排完再点名，估 15-20 张 |
| 场景底板 | **SC08-SC14 七个地点一张都没有**（丛林山路、野外营地、矿场会议室、开采工作面、矿场仓库、顾家书房、别墅门外） | 宽底板约 16 张 + 对应紧底板 |
| 新增场景 | `SC04外_板房门外`（7-3/6-2 用；剧本写"走廊"，但板房没有走廊） | 2 张 |
| 场次主帧 | 每个「场次 × 叙事节拍」一张，v2 只有 ep01 的 6 张 | 按节拍数，估 40-60 张 |
| 角色 | 顾万通/顾浩/刘兰/顾瑶 的**失势期造型**（第 10 集破产后），马库斯（7-1 出现的本地矿商） | 5-6 组三视图 |

## 制作顺序（按 skill 的既定流程）

1. ✅ **风格与叙事基调** —— 承接 v2 `style_bible.md`
2. ⬜ **资产清单**：人物清单（含造型变化集数）+ 场景清单（重要度/机位组/**焦段**）
3. ⬜ **人物提示词** —— 承接 v2 `characters.md`，补失势期造型与马库斯
4. ⬜ **场景提示词** —— 承接 v2 `scenes.md`，补 SC08-14 与全部紧底板
5. ⬜ **逐集分镜表 ep01-ep10**（新表头：加「在场人物」列；文首带**场次节拍表**）
6. ⬜ 出图（角色/场景/主帧）→ 关键帧卡 → 关键帧
7. ⬜ 镜头卡 → LTX 导出 → 生成
