## 二、场景清单：重要度 → 机位组 → **焦段**

### 定级规则（本项目自己的口径）

- **主场景** = 跨集复用 ≥2 场，或单场 ≥500 字且承载核心冲突 → `A+B+C+D`
- **次场景** = 正常演一场戏 → `A+B`
- **过场场景** = 环境交代/时间流逝，不承载对话 → `A`

### 焦段规则（v3 新增，这是和 v2 最大的差别）

> **凡是会有近景/特写落上去的机位，都要配一张 `_紧` 底板。**

依据是 v2 ep01 的实测分布：**35 镜里 22 镜（63%）是近景或特写**。
对话戏基本就是正反打近景，所以：

| 机位 | 要不要紧底板 |
|---|---|
| `A主机位` | **要**（对话戏一半的近景在这儿） |
| `B反打` | **要** |
| `C侧机位` | 主场景**要**；次场景没有 C |
| `D细节` | **不要**——`D细节` 按词表定义就是道具/手部/俯仰的细节机位，**它本身就是紧档** |

## 三、还没定的（要人拍板）

   v2 的 `D细节` 已经是二楼俯拍，但 9-1「苏慧当众下跪」和 10-1「明牌决裂」
   两场大戏都在这儿，只有四个机位可能不够用。
2. **矿场会议室 SC10 是第二主场景（1080 字、两场大戏）**，剧本里 5-1 是"一夜暴富"
   的宣布现场、8-1 是"当场被捕"，两场情绪完全相反。
   要不要**同一个房间出两套光**（5-1 亮堂 / 8-1 压抑）？

   建议一律走"文字描述 + 虚焦/背影"，不出三视图——但 8-1 的警察是抓人那一刻的
   画面主体之一，可能需要至少一组。
