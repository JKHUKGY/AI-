# 《暗局》场景/背景设计提示词

## 画风锚点（与角色提示词共用同一句）

> 现代都市短剧写实照片级质感，电影感侧逆光打光，竖屏 9:16 构图安全区设计，
> 冷暖对比色调，高细节皮肤/服装质感，无水印无文字，避免卡通化、避免五官比例
> 失真

## SC01：顶层露台派对主会场

- 出现集数：ep01
- 室内/室外：室外露天平台（顶楼），三面落地玻璃幕墙围合
- 时间/天气：夜晚，晴朗无雨
- 氛围/情绪关键词：浮夸喧闹、社交表演感、暗中窥视的羞辱氛围
- 关键陈设/构图元素：悬浮式香槟塔、暖黄色串灯缠绕的白色纱幔、城市夜景
  作为背景灯海、人群手持香槟围观的松散半圆阵型（后续镜头会用不同角度裁切
  这群"围观群演"，不必每镜重新生成）
- 光影/色调设定：暖黄/香槟色主光源（串灯+香槟塔内置灯），配合远处城市
  灯海的冷蓝背景光，形成暖光包裹人群、冷光衬托孤立感的对比
- 会用到这个场景的镜头/集数：ep01 镜1-镜7（羞辱发生的主戏段落）

### 提示词正文

```
[画风锚点] + 室外顶楼露天派对场景，悬浮式香槟塔与暖黄色串灯缠绕的白色纱幔，
三面落地玻璃幕墙围合，背景是城市夜景灯海，人群手持香槟围观的松散半圆阵型，
暖黄香槟色主光源与远处冷蓝城市灯海对比，浮夸喧闹的社交派对氛围，无人物
特写主体、场景原画，高分辨率高画质
```

## SC02：露台僻静角落（情绪转折/拨号地点）

- 出现集数：ep01
- 室内/室外：室外，同一顶楼露台的边缘僻静角落
- 时间/天气：夜晚，起风
- 氛围/情绪关键词：从喧闹中抽离的孤立感、冷静蓄力
- 关键陈设/构图元素：齐胸高的玻璃护栏、护栏外是俯瞰城市的高空景观、
  背景派对灯光被虚化压暗、只留极远处隐约的喧闹声源方向
- 光影/色调设定：冷蓝月光/城市夜景冷光为主，与 SC01 的暖黄色形成强烈色温
  反差，象征女主"退出表演、回归真实自我"
- 会用到这个场景的镜头/集数：ep01 镜8-镜10（拨打电话、复仇决心镜）

### 提示词正文

```
[画风锚点] + 室外顶楼露台边缘僻静角落，齐胸高玻璃护栏外俯瞰城市高空夜景，
背景派对灯光虚化压暗、只余极远处朦胧灯火，冷蓝月光与城市冷光为主导，
起风感，孤立冷静的氛围，无人物特写主体、场景原画，高分辨率高画质
```

## SC03：连锁崩塌蒙太奇（道具/插入镜，不需要独立环境背景图）

- 出现集数：ep01
- 说明：结尾"连锁崩塌"段落由多个手机屏幕特写（新闻推送/群消息截图风插入
  图形）与 SC01/SC02 已生成场景的人物反应镜交叉剪辑构成，不需要额外生成
  完整环境场景图，节省生成成本；手机屏幕画面内容在剪辑阶段以图形叠加方式
  制作（新闻快讯风字幕条），不进入 AI 出图流程。

## 复用建议

- SC01 只生成 1 套背景基准图，后续镜1-镜7 通过裁切/构图调整覆盖不同机位，
  不重复生成整个场景。
- SC02 同理只生成 1 套背景基准图，供镜8-镜10 复用。
