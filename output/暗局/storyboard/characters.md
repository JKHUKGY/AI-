# 《暗局》人物形象设计提示词

## 画风锚点（全剧统一，所有角色提示词开头原样复用）

> 现代都市短剧写实照片级质感，电影感侧逆光打光，竖屏 9:16 构图安全区设计，
> 冷暖对比色调，高细节皮肤/服装质感，无水印无文字，避免卡通化、避免五官比例
> 失真

---

## 角色一：顾晚晴（校园化名"陆晚"）—— 女主

- 首次登场集数：ep01
- 年龄/性别：22 岁 / 女
- 身高体态：171cm，肩背挺直但刻意收敛气场，走路步幅小、含胸——化名"陆晚"
  时刻意伪装成"低调窘迫的奖学金生"
- 发型发色：黑色中长直发，日常扎低马尾遮住耳饰痕迹
- 瞳色：深棕近黑
- 肤色：偏冷白皙
- 气质关键词：隐忍克制 / 骨相清冷（伪装下的真实底色）/ 反转后锋利果决
  → 视觉线索：伪装期低头含胸、双手交握放身前；反转瞬间脊背骤然挺直、下颌
  微抬、眼神从躲闪变为直视镜头

### 造型一：伪装期"陆晚"（本集主用，启用集数 ep01）

- 服装描述：洗得发白的浅灰色学生风针织开衫，内搭简单白衬衫，深色牛仔裤，
  帆布鞋；整体刻意朴素，与周围人形成阶级反差
- 配饰/道具：无明显配饰，手腕上有一道极淡的旧手链勒痕（暗示真实身份的
  唯一破绽，特写道具）

### 造型二：真实身份"顾晚晴"（本集结尾反转短暂闪现，启用集数 ep01 结尾）

- 服装描述：解开开衫纽扣、褪去伪装外层后露出的深色简约丝质衬衫，剪裁利落，
  质感与伪装外层形成强烈反差
- 配饰/道具：耳后一枚极小的家族徽记耳钉（此前被头发/低头姿态刻意遮住）

### 提示词正文（正面立绘，伪装期）

```
现代都市短剧写实照片级质感，电影感侧逆光打光，竖屏 9:16 构图安全区设计，
冷暖对比色调，高细节皮肤/服装质感，无水印无文字，避免卡通化、避免五官比例
失真 + 一名22岁东亚女性，黑色中长直发扎低马尾，深棕近黑瞳色，偏冷白皙肤色，
身形171cm、肩背刻意含胸收敛，穿着洗得发白的浅灰色学生风针织开衫与白衬衫、
深色牛仔裤、帆布鞋，神情低垂克制、双手交握放身前，正面全身像，干净灰色
摄影棚背景，角色设计参考图/角色立绘，高分辨率高画质
```

### 需要一次性生成的差分

1. 正面全身像（伪装期，如上）
2. 侧面/背面转身图（伪装期同套服装）
3. 近景表情差分·中性隐忍（低头、眼神躲闪）
4. 近景表情差分·被羞辱瞬间的强忍泪水（眼眶泛红但不落泪，嘴唇抿紧）
5. 近景表情差分·转折冷笑（嘴角极轻微上扬，眼神骤然锐利，脊背挺直，此表情
   同时对应造型二真实身份的解开衣领版本）

### 反面提示词

避免：多余肢体、手指数量错误、五官崩坏、水印文字、镜像不对称、妆容风格
与角色气质不符（不能显得妩媚张扬，需保持"刻意低调"的反差感）

## 角色二：封景行 —— 反派/赌局发起人

- 首次登场集数：ep01
- 年龄/性别：24 岁 / 男
- 身高体态：185cm，肩宽体态松弛慵懒，坐姿总是靠着椅背、腿随意张开，带
  居高临下的松散感
- 发型发色：深棕色微卷短发，刻意打理出随性感
- 瞳色：浅棕
- 肤色：小麦色
- 气质关键词：纨绔挑衅 / 表面随和实则算计 → 视觉线索：嘴角常挂似笑非笑的
  弧度，说话时手指无意识转动手中的酒杯/打火机

### 造型：派对西装造型（本集唯一造型，启用集数 ep01）

- 服装描述：深色天鹅绒西装外套，内搭黑色高领，不打领带，敞开一颗纽扣
- 配饰/道具：右手无名指戴一枚粗犷银戒，手中把玩一只银色打火机

### 提示词正文（正面立绘）

```
[画风锚点同上] + 一名24岁东亚男性，深棕色微卷短发，浅棕瞳色，小麦色肤色，
身形185cm、肩宽体态松弛慵懒，穿着深色天鹅绒西装外套、黑色高领内搭、敞开
一颗纽扣，嘴角挂似笑非笑的弧度，手中把玩银色打火机，正面全身像，干净灰色
摄影棚背景，角色设计参考图/角色立绘，高分辨率高画质
```

### 需要一次性生成的差分

1. 正面全身像（如上）
2. 近景表情差分·挑衅得意笑（发起羞辱时）
3. 近景表情差分·骤然色变（听闻自家资本崩盘消息时，本集结尾反应镜）

### 反面提示词

避免：多余肢体、手指数量错误、五官崩坏、水印文字、镜像不对称

## 角色三：冷屿 —— "赢家"，公开羞辱执行者

- 首次登场集数：ep01
- 年龄/性别：23 岁 / 男
- 身高体态：182cm，站姿挺拔但带表演性的"深情"姿态（伪装出的温柔人设）
- 发型发色：黑色偏软发质，微微遮眼的刘海
- 瞳色：深棕
- 肤色：偏白
- 气质关键词：伪装温柔 / 撕破脸后的轻蔑 → 视觉线索：伪装时习惯性微微侧头
  露出"体贴"笑容；撕破脸瞬间嘴角下撇、眼神轻蔑上扬

### 造型：派对休闲西装造型（本集唯一造型，启用集数 ep01）

- 服装描述：浅灰色不打领带西装，衬衫领口松开两颗纽扣，整体比封景行更显
  "斯文人设"
- 配饰/道具：手腕一块简约腕表（此前"送给"女主一条同款情侣手链，本集中
  会被当众收回/嘲讽，作为关键道具）

### 提示词正文（正面立绘）

```
[画风锚点同上] + 一名23岁东亚男性，黑色偏软发质带微遮眼刘海，深棕瞳色，
偏白肤色，身形182cm、站姿挺拔带表演性温柔感，穿着浅灰色不打领带西装、
衬衫领口松开两颗纽扣，手腕佩戴简约腕表，正面全身像，干净灰色摄影棚背景，
角色设计参考图/角色立绘，高分辨率高画质
```

### 需要一次性生成的差分

1. 正面全身像（如上）
2. 近景表情差分·伪装温柔笑（欺骗阶段回忆闪回用，本集可能不用，留档备用）
3. 近景表情差分·当众轻蔑冷笑（公开羞辱瞬间，本集核心 S 级镜头用）

### 反面提示词

避免：多余肢体、手指数量错误、五官崩坏、水印文字、镜像不对称

## 角色四：苏眠眠 —— 羞辱局的社交煽动者/直播主

- 首次登场集数：ep01
- 年龄/性别：22 岁 / 女
- 身高体态：165cm，站姿爱叉腰、爱举手机拍摄的动态感
- 发型发色：浅棕色大波浪长卷发
- 瞳色：琥珀色（美瞳质感）
- 肤色：小麦偏健康色
- 气质关键词：浮夸张扬 / 看热闹不嫌事大 → 视觉线索：总举着手机对着别人拍摄，
  夸张的肢体动作和表情

### 造型：派对亮片礼服造型（本集唯一造型，启用集数 ep01）

- 服装描述：香槟色亮片吊带礼服，浮夸大耳环
- 配饰/道具：手机（外壳浮夸，全程举着拍摄/直播）

### 提示词正文（正面立绘）

```
[画风锚点同上] + 一名22岁东亚女性，浅棕色大波浪长卷发，琥珀色瞳色，小麦
偏健康肤色，身形165cm、站姿爱叉腰、动态感强，穿着香槟色亮片吊带礼服、
浮夸大耳环，一手举着手机对镜拍摄，表情浮夸张扬，正面全身像，干净灰色
摄影棚背景，角色设计参考图/角色立绘，高分辨率高画质
```

### 需要一次性生成的差分

1. 正面全身像（如上）
2. 近景表情差分·煽动起哄的夸张笑（举手机拍摄状态）
3. 近景表情差分·直播翻车后的错愕（本集结尾反应镜，可选）

### 反面提示词

避免：多余肢体、手指数量错误、五官崩坏、水印文字、镜像不对称
